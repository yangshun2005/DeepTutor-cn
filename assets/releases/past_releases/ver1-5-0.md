# DeepTutor v1.5.0 发布说明

**发布日期：** 2026.07.04

v1.5.0 为整个 v1.4 系列画上句号，并开启下一阶段。本文不止于单点变更，而是回顾从 [v1.4.0-beta](ver1-4-0-beta.md) 到今天的整段历程——这个版本让 DeepTutor 成为 agent 原生、社区驱动的辅导平台。这几周里，社区提交了 **36 个已合并的 Pull Request**，帮助我们**解决了 53 个 Issue**。感谢大家——这个版本同样属于你们。

## v1.4.0 以来的亮点

- **Partners，源自 TutorBot。** TutorBot 成长为 **Partners**：一套生产级 IM 流水线，覆盖 15+ 渠道——Slack、Discord、Telegram、飞书、企业微信、Zulip、Matrix（可选 E2EE），以及原生 **Mattermost** 渠道——支持实时流式回复。你可以在 **My Agents** 下接入自己的 Partner，或本地 **Claude Code / Codex**，在聊天中实时咨询；每个 Partner 拥有独立的私有记忆，其对话可分支、恢复和回放。
- **统一的 agent 聊天引擎。** 聊天基于单一 agent 循环重建，**所有 OpenAI 兼容云厂商均支持原生工具调用**（以及 SiliconFlow、MiniMax M3、Qwen、Gemini 2.5+），流式输出流畅，活动栏如实反映状态。
- **真正的知识中心。** 多种检索引擎——LlamaIndex + **FAISS** 向量后端、**LightRAG**（本地与独立服务器）、**GraphRAG**、**PageIndex**，以及链接式 / Obsidian 知识库——统一在一个控制台之后，底层是可插拔的文档解析层（纯文本、**MinerU**、**Docling**、**markitdown**、**PyMuPDF4LLM**）。大知识库检索速度大幅提升。
- **引导式学习与掌握路径。** 基于聊天循环重建，带按类型区分的掌握门槛、`/learning` 仪表盘、LaTeX 渲染的测验，以及可流入题库的评分题目。
- **多用户，做对了。** 真正的按用户隔离、管理员授权、重新设计的 **User Management** 页面、带头像的自助 **Profile** 页面、默认拒绝的 MCP 工具，以及按用户隔离的会话。
- **部署加固。** 支持无根 Podman / 只读 rootfs、单端口请求时代理、可通过环境变量配置的主机绑定，以及可移植的 supervisord 配置。
- **安全加固。** Partner/TutorBot 工具沙箱已锁定，一批授权绕过、路径遍历和 RCE 报告已修复（见下文）。
- **三层记忆与更丰富的界面。** 顶层 Memory 工作台（L1/L2/L3），Partner 对话已桥接进来；Deep Research、Solve、Visualize（Animator 已合并）和 Co-Writer 持续完善。

*v1.5.0 具体而言：* 默认 LlamaIndex 引擎现在通过共享文档解析层进行摄取（因此会遵循你选择的解析引擎，并将提取的图片索引为多模态节点）；Partner 和 Soul 的 id 改为 ASCII/URL 安全，非拉丁名称也能访问；可选的 `graphrag` / `rag-lightrag` 附加包可在 Python 3.14+ 上正常安装（Issue #606，以及下述修复）。

## 升级说明

可从任意 v1.4.x 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移——现有知识库、partner、soul 和掌握路径保持原样。有两点需注意：

- **LlamaIndex 重新索引**现在通过你在 **Settings → Document Parsing** 中选择的引擎进行提取，而非旧的纯文本路径。现有索引不受影响；只有重新索引才会使用新引擎。如果文档无法提取，请确认当前引擎支持该格式（保持纯文本即可恢复旧行为）。
- **非拉丁 partner/soul id** 仅对新建实体生效——磁盘上已有的实体保留当前 id。
