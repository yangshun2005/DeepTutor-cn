# DeepTutor v1.6.4 发布说明

**发布日期：** 2026.09.03

v1.6.4 让学习工作区启动更轻、长时间任务运行更清晰、跨页面切换更稳定。Books 和 Mastery Path 新增更精细的来源与生成控制，Reading 能记住更多阅读位置，模型配置显式描述其通信协议与能力。现有工作区自动迁移；使用私有 LLM 模块的扩展作者应查看升级说明。

## 新增内容

### 更轻的启动与隔离的重负载任务

内置工具和能力改为按需加载，提供商 SDK 客户端共享有界连接池，不再无限增长。文档解析等重负载任务通过隔离的 worker 进程运行，解析器崩溃或内存飙升时不易拖垮主服务器。部署时可用 `DEEPTUTOR_ISOLATED_WORKERS` 调整并发数。

### Books 展示真实的生成计划

生成开始前，Books 显示实时章节预估，并允许选择哪些生成内容类型纳入结果。你可以生成整本书或仅生成第一章，然后跟踪真实的排队、运行、暂停、恢复和中断状态，不必猜测任务是否仍在进行。

### Mastery Path 覆盖所选材料

构建路径时，本地知识库可缩小到单个文件。若生成的主题遗漏了所选材料，覆盖审查会指出缺口，并允许你将这些文件设为必需后重新生成，或明确接受遗漏。普通 Chat 还可提供点击确认的交接卡片，用于继续 Mastery 主题或开始新的学习会话，而不会自行跳转。

### Reading 与会话保留位置

Reading 新增持久书签，恢复保存的文本或 EPUB 位置，并提供更清晰的上一单元/下一单元反馈、排版控制、可调整大小的伴随面板和笔记本导出。会话在导航间保持连续，未读状态、归档与恢复、笔记本捕获和标题更新得到更一致的保留。

### 工作区统一的活动语言

Chat、Books、Co-Writer 和侧边栏现在对排队任务、进度、完成、中断和失败采用相同的活动呈现方式。长时间运行的任务更易识别和控制，无需每个界面各自发明一套状态术语。

### 模型端点自我描述

LLM 和 Task 配置可使用 Auto 路由，或显式选择 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages。端点模型发现会追加所选模型 ID 而不替换现有条目，按模型的覆盖设置可将工具调用、图像输入、JSON 输出和推理控制标记为 Auto、Supported 或 Not supported。

## 升级说明

运行 `pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。现有设置、书籍、会话和学习数据无需手动迁移。

- 现有 `wire_api` 设置迁移为 `api_format`；兼容字段仍可读取，旧版 Anthropic 绑定继续加载。
- 旧版记忆 Markdown 从 `data/user/workspace/memory` 移至 `data/memory`。名称冲突会备份而非覆盖；请更新仍指向旧路径的外部脚本。
- 调度器依赖现在随完整应用安装，无需单独安装 `croniter`。
- 导入 `deeptutor.services.llm.executors` 下私有模块或提供商实现模块的扩展，必须迁移到公共工厂和协议接口。本版本仍保留已弃用的云端/本地兼容层。
- `DEEPTUTOR_ISOLATED_WORKERS` 为可选，默认 `2`；在极小主机上可调低，或仅在测量解析器内存后再调高。
- 英文和中文指南已在 [deeptutor.info](https://deeptutor.info/) 同步更新。
