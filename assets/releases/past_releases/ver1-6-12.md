# DeepTutor v1.6.12 发布说明

**发布日期：** 2026.09.27

在 [v1.6.11](ver1-6-11.md) 基础上，v1.6.12 支持每个工作区放置和移动其知识库、连接可搜索的 Kiwix 归档，并将来源图片带入有依据的回答。本次发布还包含任务看板、德语界面和恢复修复。现有数据无需迁移；systemd 安装现在在应用外更新。

## 新增内容

### 知识库跟随工作区

创建知识库时选择存储工作区。查看目标阻碍和受影响的分配后，可从其设置面板移动现有知识库；DeepTutor 在切换引用前验证复制的数据和索引。已保存的知识库 ID 和工作区分配继续有效。处理期间或共享授权、目标冲突、不支持的 MarginNote 数据导致不安全时，移动会被阻止。

### 连接 Kiwix 归档

从知识中心或 `deeptutor kb connect-kiwix` 将 `kiwix-serve` 提供的一个可搜索 ZIM 归档连接为知识库。搜索按需读取归档，不上传或索引副本。也可将文章带入沉浸式阅读。移除连接不会改动归档。

### 有依据回答中的来源图片

LlamaIndex 知识流水线可保留解析器提取的 PDF 和 EPUB 图片及其说明和来源位置。检索找到图片时，具备视觉能力的回答模型会看到已验证的像素；纯文本模型收到说明和上下文，并带有明确限制。沉浸式阅读可按需查看存储的图片。这取决于能输出图片的解析器，并需重新索引旧内容；见升级说明。

### 任务看板和学习控制

工作区本地任务看板跟踪待办、进行中和已完成卡片，带备注、可访问的移动控件和可恢复归档。引导学习现在遵循明确的先教偏好，并给出本地化的下一步。教师和学生加入已接受的非管理员角色值，但不获得管理员权限。

### 语言和提供商

德语加入界面语言，马来语成为回复语言选项。Cheaper Inference 加入 LLM 提供商；本地 Lemonade 嵌入无需 API 密钥即可工作。DashScope 图像、视频和语音请求使用支持的端点、尺寸和模型 ID；已保存的 DashScope `paraformer-v2` 语音配置自动迁移到 `paraformer-realtime-v2`。

### 可靠性和可访问性

失败的聊天提交在重试和存储竞争间可恢复，未回答的轮次可从丢失的工作进程恢复。LightRAG 仅复用兼容的索引缓存，检索到的图片保持在有界模型上下文内，部分 Deep Research 和 Manim 失败会报告原因。共享工具提示替换学习和工作区控件中不可访问的原生标题提示，包括触摸交互。

## 升级说明

运行 `pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。现有数据无需手动迁移。

- **Kiwix：** 为所选 ZIM 运行可访问且支持全文搜索的 `kiwix-serve` 实例，然后连接其服务器 URL 和归档名称。断开仅移除 DeepTutor 指针。
- **旧知识库图片：** 重新索引现有 LlamaIndex 源文件以创建视觉记录。MinerU 和 PyMuPDF4LLM 可输出支持的图片；默认纯文本解析器和当前 Docling 适配器不能。其他 RAG 引擎尚未索引视觉记录。
- **systemd 安装：** 运行中的服务禁用应用内更新交接。停止服务，在该服务的 Python 环境中升级 DeepTutor，然后用 `systemctl` 重新启动。
- **Windows 麦克风转录：** 原生 DashScope 和 Volcengine 语音适配器需要服务 `PATH` 中有 `ffmpeg` 来转换浏览器 WebM/Opus 音频；安装后重启 DeepTutor。OpenAI 兼容 STT 不需要本地转换。
