# DeepTutor v1.6.1 发布说明

**发布日期：** 2026.08.30

[v1.6.0](ver1-6-0.md) 打通了学习工作区。v1.6.1 关注你每天都会用到的部分：模型配置拆分为一次录入的凭据和按用途分配的配置；设置页从卡片墙变成导航器；侧边栏把学习会话归入其主题下，并允许你自行排列；LightRAG 作为一方引擎运行，不再经过封装层。可直接替换升级——无需迁移，无需重建索引。

## 新增内容

### 一个密钥，录入一次

模型配置原本是一层被复制七次的配置：每个服务各自维护自己的配置文件和凭据，因此一个 OpenRouter 密钥要粘贴到五个不同页面。现在，**连接**持有一个厂商凭据——API 密钥、版本、额外请求头、可选的端点覆盖——并向下关联到该厂商可服务的所有服务。在一处轮换密钥即可覆盖所有关联配置；删除连接只会解除关联，不会清除凭据。想为每个服务使用不同密钥？不创建连接即可。

### 任务模型

有两个没人主动关心的调用——用首轮对话为会话命名，以及在输入框下方生成起始提示——不再必须使用你为实际推理选择的模型。模型目录新增了 `task` 服务，结构与 `llm` 完全一致，因此配置方式相同，且可从 LLM 服务直接引入厂商配置，无需重新填写。留空（默认值）时，这两个调用的解析方式与之前完全一致。

### 设置页是导航器，不是枢纽

卡片网格已移除。常驻的可搜索导航器一键可达任意页面，模型 / 对话 / 智能体分类作为单页滚动，草稿在导航后保留——"保存草稿"现在真正生效。打开一个连接时，会显示它供给的服务及其各自的配置。

### 掌握路径归档自己的会话

学习会话本来就是携带 `mastery_path_id` 的普通会话；侧边栏已拥有所需全部信息，却未加利用。现在它们归入对应主题下，并在导师界面中打开——带大纲、路标标题和输入框——而不是落到 `/home` 并丢失这三者。输入框占位符由任务模型根据当前路标生成，按 Tab 可接受。

### 可自行排列的侧边栏

功能页面折叠进 **更多** 分组，导航和聊天历史均可拖拽排序——按下后需移动几个像素才成为拖拽，因此行仍可点击。排列方式是视图偏好，保存在你进行排列的那台机器上。

### 阅读伴侣就是对话界面

打开文档旁的侧边面板现在由 `/home` 自身的组件组装——相同的消息列表、输入框、活动抽屉和大纲——而不是 380 px 的重新实现。真正属于阅读本地的部分保留在本地：打开的材料、选中的段落、关联的会话，以及针对当前页面生成的占位符。阅读会话也不再被排除在侧边栏之外，而是归入其所属集合。

### LightRAG，一方实现

LightRAG 引擎直接与 SDK 通信，不再经过 RAG-Anything。`pip install 'deeptutor[rag-lightrag]'` 现在只拉取受支持的 LightRAG 版本，**不再间接引入 MinerU**——MinerU 仍是独立选择的解析器，因冲突而被迫固定的 `pdfplumber` 版本也已解除。部分接受的入口和不确定的初始候选会被保留，而不是在追加时丢弃。

### 修复

DeepSeek Pro 原生联网搜索已启用，OpenAI 绑定上的 flash thinking 已关闭；Anthropic SDK 1.x 重新通过 `extra_body` 接收 `temperature`；Jina 嵌入检索角色得到遵循。扫描版 PDF 会说明解析失败的原因，而不是报告未找到内容。认证密钥和令牌文件以仅所有者可访问的权限创建。多个发布者共用同一 slug 时，ClawHub 安装按发布者限定范围；新发送的聊天分支会被选中；`ask_user` 载荷不再泄漏 Unicode 转义。

## 升级说明

`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需手动迁移或重建索引——现有模型配置原样继续工作，连接和任务模型均为可选启用。

- **如果使用 LightRAG 引擎，请重新安装该 extra。** `pip install -U 'deeptutor[rag-lightrag]'` 会将 `raganything` 替换为 `lightrag-hku`。现有索引按原样读取。如果你依赖此 extra 一并安装 MinerU，现在需显式安装——在 **设置 → 文档解析** 中选择它，并配置其云端模式或安装其本地 CLI。
- **连接是可选的。** 现有的按服务凭据不受影响，解析方式与以往一致。仅当你希望一个密钥服务多个服务时才创建连接；关联会在保存时将凭据镜像到下游，因此每个使用方仍读取自包含的配置。
- 英文和中文指南已在 [deeptutor.info](https://deeptutor.info/) 同步更新。
