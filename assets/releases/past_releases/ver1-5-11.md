# DeepTutor v1.5.11 发布说明

**发布日期：** 2026.08.10

[v1.5.10](ver1-5-10.md) 讲的是请求底下的各条路径如何撑住；这一版讲的是答案还在写的时候发生了什么。与工具调用同处一轮的正文过去会消失在 trace 里，被截断的生成被当成模型自己决定结束，本地索引占着其他一切都要用的事件循环。设置栏也不再重复 Models 页面已经说过的内容，转而显示其他页面都没给的那个数字：DeepTutor 实际占用了多少内存。直接升级即可——无需迁移，无需重建索引。

## 新内容

### 工具调用前后的文本不再丢失

DeepSeek 的 Anthropic 兼容端点会在同一个内容流里交错输出面向用户的正文和 DSML 工具调用标记。旧的处理是全有或全无：一旦某一轮的内容通道出现 DSML 标记，该轮剩余内容就被转到 thinking 通道，模型在调用前后写的解释便从答案中消失。现在流式过滤器只增量移除 DSML 外层和 `invoke` 块——调用前、调用之间、调用后的文本都会流式输出并作为回复的一部分持久化。未完成的调用在 flush 时原样释放而非吞掉；512 字符上限确保普通正文里一个孤立的 `<` 不会让实时流永远等待闭合括号。

### DSML 数组和对象参数正确解码

DeepSeek 几乎把每个 DSML 参数都标为 `string="true"`，包括 JSON 数组和对象，因此容器参数到达工具时是一段 JSON 字符串。参数解码现在会查询声明的工具 Schema：Schema 类型为 `array` 或 `object` 的参数，在载荷确实匹配时会被解析，其余情况仍以提供方的字符串约定为准。即使提供方拒绝原生 `tools`、循环回退到 DSML，Schema 目录也会保留——而这正是解析器需要它的时候。

### 截断的生成会请求续写

`length` 结束表示生成不完整，不是模型选择停止——但它被当成了结束，于是回复在句子中间断掉。循环现在保留可见前缀并请求续写，拼装后的答案带着该前缀进入持久化和 SDK。轮次预算经过重构以保证安全：探索轮，然后一个小的有界收尾窗口，然后一次无工具的硬结束，因此反复截断和畸形的工具循环共享同一个绝对上限 `exploration + 4`。

### 设置中显示实时内存占用

设置状态栏原本显示 Backend、LLM、Embedding 和 Search——其中三项重复了 Models 和 Chat 页面已有的内容。现在显示没有任何设置页面展示的两个运行时事实：后端是否在线，以及整个 DeepTutor 进程树的常驻内存——后端、Next.js 服务器，以及所有存活的沙箱和子代理 CLI——内联给出按进程拆分，并用压力圆点在超过限额三分之二时变琥珀色。由新的 `GET /api/v1/system/memory` 提供；`psutil` 读取进程树并惰性导入，带 `/proc` 回退，因此缺少 wheel 只影响状态栏而不影响应用。非管理员和无法读取进程树的平台得到 `{available: false}`，不显示状态栏。

### 本地 LightRAG 索引不再阻塞其他一切

RAG-Anything 的本地存储后端在异步方法内部执行同步的图合并和 JSON 序列化，因此在服务事件循环上索引文档会在整个过程中冻结无关的 API 和 LLM 工作。索引现在运行在工作线程自己的事件循环上，通过一个窄桥把 LLM、视觉和嵌入调用转发回请求的循环，并携带调用方上下文的副本，使请求本地的模型和用户配置保持可见。远程 LightRAG 服务器不受影响。

### 掌握度基于持久化的问题，而非模型的复述

提出的问题现在投影为一个小型公共契约——提示、类型和选项标签/正文映射——由注册、展示和评分共享，预期答案保留在服务端。`ask_user` 渲染该持久化状态，而非模型重新编写的展示数据，因此学习者看到的选项就是将被评分的选项。注册会校验测验形状，而不是默默接受自相矛盾的形状：缺失的类型从载荷推断，`short`/`open` 题拒绝选项，选择题必须携带真实的选项正文，而非裸 `A`/`B`/`C` 标签。

### 其他

- **连接的知识库如实回答本地文件。** 链接的外部资源没有 DeepTutor 管理的 `raw/` 目录；列出其文件返回空集合而非凭空编造，需要本地文件的端点返回明确的 `409`。
- **生成的输出产物按请求作用域提供。** 新的 `/api/outputs` 端点在一次操作中解析并授权路径，无请求用户时以 `404` 失败关闭，因此认证上下文回归无法把管理员的产物交给普通请求。
- **Visualize iframe 既能缩小也能增大**——高度桥测量 body 内容，而非宿主已经拉伸的根高度，并把多次上报合并到一个动画帧。
- **聊天页的模型列表只获取一次。** 选项加载移入带单飞去重的 Hook，因此并发挂载和标签页聚焦刷新不再堆叠相同请求。

## 升级说明

`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无 Schema 变更，无需重建索引，无需迁移。

- **`psutil` 是新依赖**，随升级安装。它在 `/proc` 回退之后惰性导入——如果你的环境无法提供，内存状态栏保持隐藏，其他一切不变。
