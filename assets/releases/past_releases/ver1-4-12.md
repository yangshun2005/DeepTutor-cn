# DeepTutor v1.4.12 发布说明

**发布日期：** 2026.06.24

在 [v1.4.11](ver1-4-11.md) 基础上的知识库版本：新增 LightRAG Server 检索引擎、轻量级 PyMuPDF4LLM 解析引擎，以及让大知识库检索大幅提速的 FAISS 向量后端。可直接升级——现有知识库无需改动即可继续使用。

## 新增内容

### LightRAG Server 检索引擎

将知识库指向你自行运行的独立 **LightRAG 服务器**，DeepTutor 通过 HTTP 把检索交给它处理——不再构建本地索引。每个知识库在连接时保存自己的服务器 URL（及可选的 API Key），因此一个服务器工作区对应一个知识库，查询可使用 LightRAG 的任意模式（naive/local/global/hybrid/mix）。无需安装，引擎选择器中始终可用。

### PyMuPDF4LLM 文档解析

第五个解析引擎加入 Text-only、MinerU、Docling 和 markitdown 之列。PyMuPDF4LLM 基于 PyMuPDF（已随附），是最轻量的支持图片的选项——无需下载模型、无需 CUDA，可在低端和无 GPU 机器上运行——可将 PDF 和电子书转为 Markdown 并提取图片。使用 `pip install 'deeptutor[parse-pymupdf4llm]'` 安装；需要安装包的引擎现在可直接在 **设置 → 文档解析** 中后台安装。

### FAISS 向量检索

默认的 LlamaIndex 引擎现在通过 **FAISS** 检索，不再在每次查询时重新解析整个向量存储，因此大知识库上的搜索大幅提速。`faiss-cpu` 作为核心依赖随附，并可优雅回退到原有存储，无需额外安装。

## 升级说明

从 v1.4.11 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移。现有 LlamaIndex 知识库照常加载和查询——**重新索引**知识库即可迁移到更快的 FAISS 后端。新引擎为可选启用：在创建知识库时或设置中选择 LightRAG Server 或 PyMuPDF4LLM。
