# DeepTutor v1.6.3 发布说明

**发布日期：** 2026.09.02

v1.6.3 包含一次**破坏性的前后端重构**，用严格的规范契约替换了兼容路由和流式入口，同时新增学习者与监护人账户、基于资料的 Reading 操作、更广的知识库与解析支持，以及 Python 3.14 支持。工作区数据原地迁移，但使用已停用 URL 的书签和外部客户端必须更新。

## 新增内容

### 破坏性的前后端重构

Home 现在运行在服务器权威的轮次协议和类型化前端契约之上。Web 资源拥有规范、可收藏的 URL；Chat、Mastery Path 和 Reading 会拒绝多余的会话路径段，而不是静默接受；登录返回路径保留查询参数和哈希，同时禁止外部重定向。所有 WebSocket 现在都位于 `/ws/...` 下，旧的前端兼容入口已移除。

### 学习者账户与监护人闭环

管理员可创建 Standard、Learner 或 Custom 账户。学习者档案会将年龄、年级、课程、语言、阅读水平和讲解偏好带入导师；服务器强制执行的策略约束可用能力和已批准材料。获授权的监护人可分配或移除材料、读取进度报告，并重置可撤销的设备凭据（带过期时间和每日限额）。

### Reading 成为主动学习界面

沉浸式 Reading 新增经过验证的可点击引用、已保存的引用和笔记、基于资料的朗读、学习指导、词汇、测验、翻译和笔记本捕获。Home 可将回复转为内联 Markdown 笔记，沉浸式观看则保存带时间戳的转录笔记，并重试不可用的 Invidious 字幕。

### 长时间任务可干净地停止与恢复

书籍生成支持持久暂停：取消排队中和进行中的工作而不丢失已完成页面，仅在请求时恢复，并在模型反复失败时自动暂停。Chat、Book、Knowledge 和 Memory 流使用单调游标、重放、去重和终态恢复；测验评判和子代理咨询可停止，并受超时限制。

### 更多知识引擎、更快的本地检索、更广的解析

可连接自托管的 WeKnora 知识库，无需复制其文档或构建本地索引。LlamaIndex 新增可选的交叉编码器重排序，以及 exact-flat 或 HNSW FAISS 索引；LightRAG 可使用专用模型。文档解析现在遵循各引擎当前的格式目录，包括 Docling、Tika、PyMuPDF4LLM、LiteParse 和 markitdown 的广泛覆盖。

### 更多提供商与创作选择

DashScope 加入文本转语音、语音转文本、图像和视频生成。OpenAI 兼容配置可显式选择 Responses 或 Chat Completions，推理状态跨轮次保留。Co-Writer 可导入 `.docx` 草稿并导出 Word，设置中新增可搜索工具。

### 更安全的报告、沙箱和启动器

Deep Research 会重试不完整的报告章节，且不会泄漏重复的部分文本。本地执行强制输出和进程限制。启动器新增 macOS 启动命令、浏览器安全的 Windows 行为、分离/无浏览器运行，以及 `deeptutor stop`；中断的聊天流也能更可靠地恢复。

## 升级说明

运行 `pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。现有设置、账户、知识索引、书籍、Reading 状态和会话无需手动迁移或重建索引；启动时会原地迁移旧版聊天和工作区偏好数据。

- **更新书签和自定义前端。** 规范会话路由为 `/chat/{sessionId}`、`/mastery/{pathId}/sessions/{sessionId}` 和 `/reading/{workspaceId}/sessions/{sessionId}`。资源路由为 `/books/{bookId}/pages/{pageId}`、`/notebooks/{notebookId}` 和 `/knowledge-bases/{kbName}`。已停用的 `/space/learning/*`、`/partners/groups` 和 `/settings/about` 入口不再重定向；请使用 `/mastery`、Partner 工作区和 `/settings#about`。
- **更新 WebSocket 客户端。** 规范命名空间为 `/ws`、`/ws/books`、`/ws/questions/*`、`/ws/knowledge-bases/{kbName}/progress`、`/ws/mastery-paths`、`/ws/partners/{partnerId}` 和 `/ws/partner-groups/{groupId}`。带 API 前缀的旧版 socket 已移除。

- **核心应用和 CLI 支持 Python 3.14。** GraphRAG 仍支持 Python 3.11–3.13。在 3.14 上，当可选 BM25 依赖不可用时，LlamaIndex 回退到向量检索。
- **刷新可选解析器扩展。** 支持的最低版本为 markitdown 0.1.7、Docling 2.123.1、PyMuPDF4LLM 1.28.2、LiteParse 2.14.2、MinerU 3.4.5 和 Apache Tika 4。旧版引擎会提示需要更新，而不是针对不兼容的 API 运行。
- 英文和中文指南已在 [deeptutor.info](https://deeptutor.info/) 同步更新。
