# DeepTutor v1.4.4 发布说明

**发布日期：** 2026.06.13

本次发布在 [v1.4.3](ver1-4-3.md) 基础上聚焦两点：技能库向更广泛的 Agent-Skills 生态开放——一条命令即可从 [ClawHub](https://clawhub.ai/) 安装社区技能——知识库文档预览也追平了聊天文件查看器。完全可直接升级，无需迁移，无破坏性变更。

## 新增内容

### Hub 技能，一条命令即可安装

DeepTutor 技能与 Agent-Skills 生态格式相同（`SKILL.md` + 支持文件），因此外部注册表现在可直接作为技能库的来源：

```bash
deeptutor skill search "git release notes"        # 在 hub 上语义搜索
deeptutor skill install clawhub:gh-release-notes  # 校验 → 拉取 → 注册
deeptutor skill install some-skill@1.2.0          # hub 默认为 clawhub；@ 指定版本
deeptutor skill list                              # 列出本地技能及其 hub 来源
```

无论来源如何，每次导入都经过同一道安全门：先检查 hub 的安全判定（被标记的包会被拒绝，除非使用 `--allow-unverified`）；解压归档时防范 zip-slip / zip-bomb；支持文件需通过文本/脚本后缀白名单，二进制文件绝不会落入工作区；`always:` frontmatter 会被剥离——下载的包永远无法把自己注入每个系统提示词。来源信息（hub、版本、判定）记录在 `.hub-lock.json` 中供审计。ClawHub 之外的注册表可通过 `settings/skill_hubs.json` 接入。

在多用户部署中，安装仅限管理员（`POST /api/v1/multi-user/admin/skills/install`），且安装 ≠ 分配：技能进入管理员目录，在授权分配之前对其他用户不可见——管理员可以先在自己的对话中审查 hub 技能。

### 知识库预览，真正可用

知识库文件标签页现在可在浏览器中渲染 Word 和 Excel 文档——与聊天文件查看器在 v1.4.3 中获得的 docx/xlsx 预览器相同——新增的 `file-preview-text` 端点按需提供提取的纯文本，因此 PowerPoint 及其他 Office 文件以文本形式预览，而不是显示下载按钮。DOCX 预览器还学会了缩小页面以适应狭窄侧栏，而不是裁切页面。

### Markdown 预览渲染内嵌图片

包含 base64 内嵌截图的自包含 markdown 文件现在可以显示图片：渲染器允许图片使用安全的栅格 `data:image/*` URL（react-markdown 默认会剥离所有 `data:` URL），而可执行脚本的 scheme 仍被阻止。

### 本地化 README，重新同步

全部十个翻译版 README（中文、日本語、Español、Français 等）已基于当前英文 README 重建——包含 Partners、v1.4.x 发布历史以及更新后的布局。

## 升级说明

- 可从 v1.4.3 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移。
- `deeptutor skill install` 通过 HTTPS 访问 clawhub.ai；隔离网络部署可通过 `settings/skill_hubs.json` 指向镜像或 fetch CLI。
