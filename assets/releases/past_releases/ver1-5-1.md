# DeepTutor v1.5.1 发布说明

**发布日期：** 2026.07.09

在 [v1.5.0](ver1-5-0.md) 基础上的小版本发布：卡在错误状态的知识库不再是死路——你可以删掉那个解析失败的文档继续用，不必删除并重建整个知识库。直接升级，无需迁移。

## 新增内容

### 删除单个文档——错误状态的知识库也能删

现在可以在「文件」标签页中从知识库删除单个原始文档，即使知识库处于**错误**状态也能操作。此前，解析失败的文件（例如超出云端解析器页数限制的 PDF）会让整个知识库被锁住，唯一的出路是删除并从头重建。现在只需删掉出问题的文件，上传替代文件，或用剩余文档重试索引。删除与索引解耦——无需可用的索引即可执行——已索引文件的向量会在下次重建索引时被清除。

## 升级说明

从 v1.5.0 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移，行为无变化——现有知识库、伙伴和掌握路径照常工作。已连接（只读）和旧版知识库仍不支持按文件删除，与之前一致。
