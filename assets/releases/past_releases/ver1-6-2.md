# DeepTutor v1.6.2 发布说明

**发布日期：** 2026.08.31

v1.6.2 新增沉浸式 YouTube 学习与插件驱动的可视化器目录，并优化了阅读、知识、伙伴、更新和 My Agents。唯一的不兼容变更是移除 Playground API 与 Gemini CLI 连接。

## 新增内容

### 在同步视频旁学习

粘贴 YouTube URL，即可在导师旁打开隐私增强播放，将转录证据绑定到时间戳、讲解当前提示，并稍后恢复进度。管理员可选择自托管的 Invidious 源，无需重建材料；原生播放无需可选的公开字幕适配器。

### 通过可扩展目录进行可视化与咨询

Visualize 现使用共享 agent 循环和已安装的可视化器目录，支持 SVG、Mermaid、Chart.js、交互式 HTML、Manim 及可选 GeoGebra。声明式纯浏览器可视化器 ZIP 在沙箱 iframe 中运行。My Agents 在六个现有本地 harness 之外新增 Hermes Agent、OpenClaw 和 DeepSeek Harness。

### 更紧凑的首页、阅读与更新路径

首页统一了普通、阅读、掌握和观看工作区中的聊天行为。网页来源变为安全的版本化快照，阅读引用仅在经本轮材料验证后建立链接，LaTeX 选区保持有据可依，设置 → 关于可检查、分类并安全应用符合条件的 PyPI 更新。

### 更清晰的知识与伙伴操作

MinerU 现除 PDF 外还接受常见栅格图像及 DOCX、PPTX、XLSX。知识中心将库与本地、服务器、云和外部引擎分离，并提供就绪预检。伙伴渠道卡片报告实时连接/设置状态（包括浏览器二维码引导），不再将常规诊断发送到日志。

## 升级说明

运行 `pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。现有数据、知识索引、视频进度和阅读快照无需迁移。

- **公开字幕辅导为可选功能。** 安装 `pip install -U 'deeptutor[video-learning]'` 以启用基于转录的视频讲解。YouTube/Invidious 播放无需此功能仍可正常工作。
- **Gemini CLI 不再作为 My Agents harness。** 现有 `gemini` 设置保持不变但不再注册；旧设置路由重定向至 Antigravity。请改为连接 Antigravity、Hermes Agent、OpenClaw 或 DeepSeek Harness。
- **Web Playground 和 `/api/v1/plugins/*` 测试 API 已移除。** `deeptutor plugin list/info` 仍可检查运行时工具与能力。浏览器可视化器现使用 `/api/v1/visualizers` 和声明式可视化器包。
- 英文与中文指南已在 [deeptutor.info](https://deeptutor.info/) 同步更新。
