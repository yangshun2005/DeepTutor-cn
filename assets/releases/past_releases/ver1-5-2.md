# DeepTutor v1.5.2 发布说明

**发布日期：** 2026.07.19

这是 [v1.5.1](ver1-5-1.md) 之上的维护版本：聊天附件限制现在可自行调整，PageIndex 通过跨文档推理进行检索，并修复了提供商、Book 和知识库的大量可靠性问题。可直接升级，无需迁移。

## 新增内容

### 可配置的聊天附件限制

附件大小上限和提取文本预算现可在 **设置 → 聊天 → 附件**（仅管理员）中编辑：包括单文件和单轮上传上限，以及单文档和单轮字符预算，存储在 `system.json` 中，可通过 `CHAT_ATTACHMENT_*` 环境变量覆盖。这也修复了大文件上传时静默断开连接的问题——WebSocket 帧上限现在根据总上限推导，而非固定默认值。降低限制在下一消息生效；将大小上限提高到当前帧上限以上需要重启。

### PageIndex 通过跨文档推理进行检索

PageIndex 知识库现在通过内部 MCP 服务器查询，聊天通过对文档树发起代理式工具调用来检索，而非单一固定查找——多步问题可获得更精准的页面级引用。数据导入现支持更多格式：PDF、Office（Word / PowerPoint / Excel）、Markdown、纯文本和 CSV。

### 更广泛、更稳定的模型支持

- 较新的 Anthropic 和 OpenAI 模型通过其官方 SDK 工作，包括 OpenAI Codex 原生工具调用。
- 基于 effort 的 Claude 模型自适应驱动扩展思考，而非固定 token 预算；温度拒绝模型集已修正，不支持的模型不再报错。
- 流式 token 用量每次完成只计一次，修复了用量和成本统计虚高的问题。

### 更稳定的 Book 和知识库

- 卡在 GENERATING 或 PLANNING 状态的 Book 页面会在失败时被恢复并重置，后台编译错误不再使页面卡死。
- 知识库在上传和文件夹同步时更新状态，链接文件夹同步状态持久化，所有管理器写入均为原子操作——崩溃后不再出现写了一半的 JSON。

### 聊天和渠道优化

全宽聊天配单一、可预期的滚动条；输入框和消息列对齐；**Enter** 发送已编辑消息（**Shift+Enter** 换行）；格式错误的 Markdown 链接不再导致渲染器崩溃。企业微信合作伙伴已对齐 SDK 1.0.8，Mastery Path 近期权重已恢复（[#618](https://github.com/HKUDS/DeepTutor/issues/618)）。

## 升级说明

从 v1.5.1 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移——现有知识库、合作伙伴和 mastery path 继续可用。新的附件默认值较宽松（单文件 20 MB，单轮 25 MB；字符预算 200k / 150k），除非在 **设置 → 聊天 → 附件** 中调整，否则无变化；仅将大小上限提高到当前 WebSocket 帧上限以上需要重启。
