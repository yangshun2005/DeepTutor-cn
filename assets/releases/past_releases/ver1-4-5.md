# DeepTutor v1.4.5 发布说明

**发布日期：** 2026.06.14

本次发布在 [v1.4.4](ver1-4-4.md) 基础上聚焦几项改进：Guided Learning 重建于驱动其余所有功能的同一聊天代理循环之上，并基于新的循环插件框架，使聊天循环可扩展。Partner 对话新增导出与保存到笔记本功能，每轮聊天现在能更快完成。直接替换升级，无需迁移。

> **Guided Learning 的运行方式已改变，但你的进度会保留。**
> 旧的固定阶段流程被替换为带硬性掌握门槛的导师聊天。现有学习进度原样加载——无需迁移，无需任何操作。唯一需要操作的变化针对 Windows：启动脚本已移入 `scripts/`（见升级说明）。

## 新增内容

### Guided Learning 重建于聊天循环

定制的阶段状态机（诊断 → 讲解 → 测验 → 费曼）已移除。掌握路径现在是一对一导师聊天，驱动按类型划分的硬性掌握门槛，未通过门槛不会推进到下一个目标：

- **记忆 / 流程**类目标通过交互卡片测验，由服务端评分——预期答案与题目一同存储，绝不经过模型往返——随后安排间隔重复复习。
- **概念 / 设计**类目标通过用自己的话复述来掌握；导师评判并记录结果。
- `/learning` 页面现在是**仪表盘**：显示门槛决定的下一步，以及每个目标的状态图（新 / 学习中 / 已掌握）。

### 可扩展的聊天循环

新的循环插件框架（`deeptutor/loop_plugins/`）让功能可以向一轮对话贡献其工具、系统提示块和服务端持有的工具参数，而无需聊天流水线硬编码。Guided Learning 是第一个插件。该循环还学会了**上下文检查点折叠**——工具可以在轮次中途将较长的工作上下文折叠回检查点加摘要。日常不可见；这是未来模式接入的接缝。

### Partner：导出与保存到笔记本

Partner 的 **Chat** 和 **Archive** 对话现在可以导出为 Markdown 并保存到笔记本——与产品 Chat 已有的控件相同，现由同一个共享序列化器支撑。

### 更快的轮次完成

每轮聊天现在在答案保存的那一刻就发出 `done` 信号，因此输入框立即解锁、计时器立即停止；自动生成的会话标题稍后跟上，不再拖住轮次。

## 升级说明

- 从 v1.4.4 直接替换升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移——现有学习进度原样加载。
- Windows 启动脚本已移入 `scripts/`：运行 `scripts\start_backend.bat` / `scripts\start_frontend.bat`。
