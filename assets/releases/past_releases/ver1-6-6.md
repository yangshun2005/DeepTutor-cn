# DeepTutor v1.6.6 发布说明

**发布日期：** 2026.09.08

v1.6.6 是一个修复版本，而且异常清晰。梳理 v1.6.5 的反馈后发现，用户报告的问题大多并非回归：v1.6.5 主要移除了此前掩盖旧缺陷的东西，于是静默提交失败的答案、从未真正成功却报告成功的复制按钮、自 v1.6.0 起就无法使用的阅读操作，一次性全部暴露出来。本次一并修复，以及背后的社区 Pull Request 批次。直接替换升级——无需迁移。

## 新增内容

### 提交的答案真正送达

`ask_user` 卡片的轮次已结束时，卡片无法再到达后端，提交因此毫无反应。更糟的是，提交被拒时三个输入框会丢弃已输入的内容，而错误提示却让你发送新消息——而这正是被阻止的操作。两处均已修复：已结束但仍有未回答卡片的轮次保留其地址，被拒的答案改为以普通消息重新发送，不再丢弃。

自 v1.6.3 起，含答案图片的笔记本条目完全无法保存——插入语句列出 23 列却只提供 22 个值，每次都抛出 `OperationalError`。

### 首次加载明显更轻

生成的品牌图标表——每个商店 logo，约 95 KB——仅为一个页脚链接就搭进了所有路由共享的应用外壳 chunk。现已移出；侧边栏的会话组织 UI 和 Co-Writer 笔记本选择器改为按需加载；首页路由从 305 KB 降至 203 KB，预算为 300 KB。已无路由超出预算。

### 复制真正复制

无论内容是否进入剪贴板，复制按钮都报告成功，并通过 `aria-live` 播报这一虚假成功——屏幕阅读器用户被告知复制成功，实际并未成功。现在会在第一个 `await` 之前探测剪贴板访问权限（过早消耗用户手势额度是根本原因），真实失败会如实显示。

### 知识库：名称、上传、空库

用斜杠命名的知识库可以创建，却永远无法删除。校验逻辑现位于管理器上，八个注册入口共享，已存在的非法名称也可删除。传输中途失败、只报 "Failed to fetch" 的大文件上传也已修复：代理重放了客户端的 `Expect: 100-continue` 头，undici 会直接拒绝。创建空知识库不再抛出进度错误。

### 伙伴可使用你连接的知识库

将 Obsidian vault、链接索引、WeKnora 或 IMA 分配给伙伴过去会直接失败：预配逻辑只会复制文件夹，而指针型知识库按设计没有文件夹。连接型知识库现以指针方式注册，在伙伴的库中保持可见，也可再次移除。Obsidian、MarginNote 和子代理知识库被有意拒绝——它们各自驱动一项独占能力，会接管该伙伴的每一轮对话。

伙伴在聊天中呈现的文件，由提问者下载；伙伴对话现在显示来源聊天，飞书群话题不再与私信无法区分。

### 聊天不再调用不存在的工具

`read_source` 属于答案循环之前运行的上下文调查器，不属于循环本身。提示词和附加来源清单却说法相反，模型因此不断尝试用从未获得的文件工具重新打开 PDF。

### 推理内容在缺失处补齐

共享的 agentic 循环从未捕获轮次的推理内容——其结果类型上没有该字段——因此基于它的界面（包括书籍测验）显示的是提供方推理错误而非内容。现已贯通传递。

### Codex 登录可在 Docker 内完成

浏览器无法访问容器的回环回调时，可粘贴浏览器最终落到的地址完成登录。粘贴的地址必须与该次尝试注册的重定向 URI 完全一致，重复的 OAuth 参数会因歧义被拒绝；该地址仅被解析后丢弃，绝不抓取、存储或回显。目录兼容版本也已提升，旧版本遗漏的合格模型现在会出现。

### 值得一提的小修复

四项需要选中文本的阅读操作自 v1.6.0 起无法用鼠标使用——标注弹窗在点击落地前就解除了工具栏。向导师请求另一种语言已可用，该偏好的浏览器端与服务端副本不再漂移。Mastery Path 将 `mastery_mode` 识别为重新绑定路径的工具。学习者账户可再次打开课程。格式错误的 `###heading` 文本会被规范化，且不影响代码围栏内的 `#include`。

## 修复

Moonshot Kimi `k3` 系列按系列命名而非按每个已发布 id 命名，`k3-256k` 及后续变体得以保留温度覆盖；因不支持的 `input[N].status` 被拒的 Responses 请求会去掉该字段重试一次并记住该模型；LightRAG SDK 从候选版本迁移到 1.5.7；README 概览截图已更新。

## 升级说明

运行 `pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移。

- **回滚到 v1.6.4 几乎无法修复上述任何问题。** 这些缺陷大多早于 v1.6.5；只有知识库命名和 Mastery Path 问题属于 v1.6.5 真正新增的改动面。
- 如果自定义提示词或插件要求答案循环调用 `read_source`，请将该工作移至上下文调查器——循环不会挂载它。
- 英文和中文指南已在 [deeptutor.info](https://deeptutor.info/) 同步更新。
