# DeepTutor v1.5.4 发布说明

**发布日期：** 2026.07.24

这是 [v1.5.3](ver1-5-3.md) 的当日维护更新，聚焦聊天体验：回答后的"生成中"卡顿已消除，IM 合作伙伴能忠实渲染 Markdown 表格，模型返回的 JSON 解析更稳健。可直接升级，无需迁移。

## 新增内容

### 聊天响应性

- 回答流式输出结束后持续数秒的"生成中…"卡顿已消除：本轮完成事件现在携带已持久化的消息 id，前端就地核对，不再重新拉取并重渲染整个会话；轮次事件在单个事务中刷出（[#678](https://github.com/HKUDS/DeepTutor/issues/678)）；流式自动滚动不再每帧强制布局。
- 助手仍在流式输出时按 Enter，不再触发第二条交错消息（[#674](https://github.com/HKUDS/DeepTutor/issues/674)）。

### 忠实的 IM 表格

各合作伙伴渠道统一了 Markdown 表格处理，修复了 Slack（[#679](https://github.com/HKUDS/DeepTutor/issues/679)）和飞书（[#683](https://github.com/HKUDS/DeepTutor/issues/683)）表格中空单元格被丢弃，以及空行被误读为表头分隔符（[#682](https://github.com/HKUDS/DeepTutor/issues/682)）的问题。

### 更稳健的 LLM 输出解析

结构化输出能应对更杂乱的模型响应：解析前会剥离 `<think>` 推理标签（[#675](https://github.com/HKUDS/DeepTutor/issues/675)）；JSON 值后紧跟相邻值时不再破坏 Deep Research 提取（[#680](https://github.com/HKUDS/DeepTutor/issues/680)）；解析器返回最长的可解码值，而非找到的第一个前缀（[#692](https://github.com/HKUDS/DeepTutor/issues/692)）。

### 其他修复

- 流式输出中途生成的测验卡片限定在本轮内——新测验不再继承（并静默重报）上一份测验的答案（[#677](https://github.com/HKUDS/DeepTutor/issues/677)）。
- 另一个知识库在后台建索引时，创建知识库表单不再丢失已输入内容和已加载文件（[#691](https://github.com/HKUDS/DeepTutor/issues/691)）。
- Math Animator 将 `500ms` 按毫秒而非分钟解析（[#681](https://github.com/HKUDS/DeepTutor/issues/681)）。

## 升级说明

可从 v1.5.3 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移，无 Schema 或配置变更。
