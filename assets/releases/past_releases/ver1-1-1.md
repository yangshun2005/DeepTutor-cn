# DeepTutor v1.1.1 发布说明

**发布日期：** 2026.04.17

## 亮点

### 通用"立即回答"逃生通道 — 按能力区分的快速路径
将"立即回答"从仅限聊天的功能升级为通用中断机制，并遵循各能力的输出形态。新增共享辅助模块 `deeptutor/capabilities/_answer_now.py`，提供门控（`extract_answer_now_context`）和便于提示词使用的追踪摘要；每个内置能力现在都在 `run()` 顶部拥有自己的快速路径分支：

- `chat` — 从部分追踪中合成最终 markdown 答案（原有行为）。
- `deep_solve` — 跳过规划 + 推理，直接进入写作器。
- `deep_question` — 跳过构思/模板，通过一次结构化调用输出完整测验 JSON（仍由 `QuizViewer` 渲染）。
- `deep_research` — 跳过改写/分解/研究，直接从已积累的证据撰写报告。
- `math_animator` — 跳过分析 + 设计 + 总结，但**保留代码生成 + 渲染**，用户仍能获得真实动画。
- `visualize` — 跳过分析 + 审查，通过一次结构化调用输出最终可渲染代码。

每条快速路径都保留与正常流水线相同的结果封装（因此 Quiz / MathAnimator / Visualization 查看器渲染不变），并在开头添加 `> ⚡ Skipped X stage(s)` 提示，让用户知道这是尽力而为的提前退出。编排器不再将 `answer_now` 重新路由到 `chat`；现在会保留 `active_capability`，仅当原选能力已从注册表中移除时才回退到 `chat`。前端同步调整：`handleAnswerNow` 不再覆盖快照中的能力，单次受保护的 `AnswerNowRow` 组件在流式追踪面板下方内联渲染该操作。

### 协同写作 — 可调整分栏与按行锚定的滚动同步
协同写作页面在编辑器和预览窗格之间新增可拖拽分隔条（比例持久化到 `localStorage`），并实现真正的双向滚动同步，可正确处理软换行。每个预览块现在携带 `data-source-line` 属性，指回其在 markdown 源中的起始行（由 remark 的 AST 位置提供）；编辑器侧使用隐藏镜像元素模拟 textarea 的换行几何，从而读取每个源行的真实像素 `y` 坐标。两侧均以像素坐标表示后，同步变为任一方向上的单段分段线性插值，并带有按源行缓存，仅在内容或换行宽度变化时失效。

### 保存到笔记本 — 消息选择模式
`SaveToNotebookModal` 现在接受可选的 `messages` prop，将模态框切换为"选择模式"：用户精确挑选要包含的用户/助手轮次，发送到后端的转录 + `userQuery` 由所选子集重建。快捷预设（"全选"、"最后一轮"、"最近 3 轮"）和自动推导的标题（跟踪第一条选中的用户消息）让常见场景保持高效。模态框还使用 `Check` / `MessageSquare` / `User` 图标一眼区分角色，并将笔记本列表的加载状态与保存 spinner 分开报告。

### 全栈采用真实笔记本系统
将所有剩余的笔记本界面从旧版测验分类 API 迁移到真实的 `/api/v1/notebook/*` 端点。新增 `web/lib/notebook-api.ts` 块导出类型化辅助函数 — `listNotebooks`、`getNotebook`、`createNotebook`、`updateNotebook`、`deleteNotebook`、`deleteNotebookRecord` — 同时保留仅测验用的辅助函数。知识 → 笔记本标签页、指南页的笔记本引用选择器（`useNotebookSelection`）以及保存到笔记本模态框现在都端到端解析 UUID，因此从协同写作、聊天或引导式学习保存的记录可立即在各处作为引用被发现。

### 统一可折叠设置面板
将此前仅存在于 `ResearchConfigPanel` 的可折叠"设置"区域提取为共享的 `CollapsibleConfigSection` 组件。Quiz、Math Animator 和 Visualize 面板现在共享完全相同的 chevron + 摘要标题，每个表单都附带 `summarizeXxxConfig` 辅助函数，使折叠状态显示有意义的一行摘要（例如 *Custom · 5q · Hard · MCQ* 或 *Mimic · paper.pdf · max 10*）。聊天页面现在为当前激活的能力保留单一 `panelCollapsed` 状态，切换能力时自动展开，发送消息后自动折叠，使对话期间输入区保持紧凑。

### 流式停止按钮与输入区打磨
将发送按钮内的 spinner 替换为专用的 **Stop** 按钮，在轮次流式传输时取代发送按钮出现。一圈淡色圆环沿边缘缓慢旋转，表示"仍在工作 — 点击取消"，中央白色方块作为点击目标。消息上方的标题栏（能力标签 + 保存 / 新聊天按钮）现在始终渲染，消息容器顶部和底部添加柔和遮罩渐变，使流式内容淡入淡出而非在滚动边缘被裁切。在深度研究模式下，来源移入下拉菜单，并附当前选择的紧凑摘要行，与工具选择器的模式一致。

### TutorBot 配置管理器重构
将 `TutorBotManager` 的配置持久化重写为小型公共 API（`load_bot_config`、`save_bot_config`、`merge_bot_config`），带来三项实质性改进：写入现在**原子化**（写临时文件 + `Path.replace`），进程被杀也不会留下半写的 `config.yaml`；合并具有**显式清除语义** — `None` 表示"保持原样"，空字符串或空字典表示有意清除 — 因此客户端可以刻意清空描述或频道列表；API 端点仅转发 `model_dump(exclude_unset=True)`，省略的字段回落到磁盘上的值。新增回归测试覆盖原子写入契约、损坏 yaml 回退以及四种合并语义场景。

### Markdown 渲染器改进
`MarkdownRenderer` 系列新增 `trackSourceLines` prop，将 `data-source-line` 属性传播到每个块元素（标题、列表、段落等），并绕过行偏移规范化处理（`processMarkdownContent`、`normalizeMarkdownForDisplay`），使 AST 位置对编辑器/预览同步消费者保持忠实。`RichCodeBlock` 现在对无标签 / `text` / `plaintext` 围栏完全跳过 `react-syntax-highlighter`（消除 Prism "unknown language" 警告），并将其渲染为整洁的纯等宽块。Mermaid 检测也扩展为识别 editor.md 风格的 ` ```flow `、` ```seq ` 和 ` ```sequence ` 围栏，这些会被预处理器重写为 mermaid。

### 主题与指南 UI 刷新
收紧默认浅色和 Snow 主题，使用更深的前景色、更暖的边框和略微更饱和的 `--primary`（`#B0501E`），以在新的卡片表面上获得更好的可读性。引导式学习页面（`/guide`）从硬编码的 `slate-*` / `indigo-*` 调色板迁移到设计令牌（`var(--card)`、`var(--primary)`、`var(--muted-foreground)` 等），现在遵循主题切换器。`HistorySessionPicker` 获得相同处理，并修复了会话时间戳被当作毫秒而非秒处理的问题（曾产生 1970 年日期）。

### 系统消息渲染修复
后端系统消息（例如轮次运行时写入的测验后续 grounding 上下文）现在在 `UnifiedChatContext.hydrateMessages` 边界被过滤，并在 `ChatMessageList` 中再次防御性过滤，因此它们不会在 UI 中显示为幽灵聊天气泡，同时仍按预期流入 LLM 上下文。

### Bug 修复
- **TutorBot 频道配置在每次服务器重启时被清空 (#332)** — `create_and_start_bot` 每次调用都构造带空默认值的新 `BotConfig`，随后 `_save_bot_config` 将其持久化覆盖现有 `config.yaml`，清空用户配置的频道（例如 Telegram）。端点现在先加载现有配置，仅覆盖客户端提供的字段。
- **`selective_access_log` 中间件在每个非 200 响应时崩溃 (#334 / #335)** — 中间件向 uvicorn 的 `AccessFormatter` 传递四个参数，而它期望五个（缺少 `http_version`），导致每个错误响应都抛出 `ValueError: not enough values to unpack`。现在从 ASGI scope 读取 `http_version`，回退为 `1.1`。
- **15 个 npm 安全漏洞 (#330)** — 升级 `jspdf` 4.0.0 → 4.2.0（9 个 CVE，含严重 PDF 注入）、`next` 16.1.1 → 16.2.3（8 个 CVE，含 HTTP 走私、CSRF 绕过）、`mermaid` 11.12.2 → 11.14.0，以及匹配的 `eslint-config-next`。`npm audit fix` 清理了间接依赖链（`flatted`、`lodash-es`、`minimatch`、`picomatch`、`dompurify`、`ajv`、`brace-expansion`）。最终状态：0 漏洞，无破坏性变更。
- **`.env.example_CN`** — 移除了提供商列表注释上误加的 `// README` 后缀。

### 测试套件扩展
新增 `tests/services/tutorbot/test_manager_config.py` 模块，覆盖加载/保存往返、损坏 yaml 回退、原子临时文件写入、写入中途 `OSError` 后的故障恢复，以及全部四种 `merge_bot_config` 语义（无现有配置、省略字段透传、`None` 视为未提供、空值视为显式清除）。扩展 `tests/api/test_tutorbot_router.py`，加入显式清除测试类。重写编排器 answer-now 路由测试以固定新契约 — 设置 `answer_now_context` 时保留 `active_capability`，仅当原能力缺失时编排器回退到 `chat`，两者均未注册时发出明确错误。新增 `tests/capabilities/test_answer_now.py` 模块，含 28 个用例，覆盖共享辅助函数（`extract_answer_now_context`、`format_trace_summary` 截断/i18n、`make_skip_notice`、`labeled_block`、`join_chunks`）以及每个按能力的快速路径：`chat`、`deep_solve`、`deep_question`（含不可解析 JSON 回退）、`deep_research`、`visualize`（含代码围栏剥离和无效 `render_type` 恢复）、`math_animator`（验证 `run_analysis`/`run_design`/`run_summary` *不被*调用，而 `run_code_generation`/`run_render` *被*调用）。反向测试确认无 `answer_now_context` 时能力仍走正常流水线。
