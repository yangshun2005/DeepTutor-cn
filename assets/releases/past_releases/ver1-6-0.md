# DeepTutor v1.6.0 发布说明

**发布日期：** 2026.08.27

[v1.5.17](ver1-5-17.md) 让 Partner 支持个性化，并让知识库能够跟踪 GitHub。v1.6.0 打通学习工作区的其余部分：忠实于源文件的阅读、Courses 与 Little Tutor 线程、Ask Questions 模式、有边界的网页来源同步，以及在不共享读者学习状态的前提下共享 Books。现有数据保持原位；多用户管理员只需在需要的地方授予 Book 访问权限。

## 新增内容

### 沉浸式阅读升级为完整阅读器

EPUB 与 PDF 一同进入忠实于源文件的视图，支持按格式生成大纲并保存阅读位置。W3C 文本选择器让高亮在重排后依然附着，Recogito 负责渲染注释，提取文本视图新增持久化的排版与颜色控制，已安装的 Reading 扩展只能通过受限协议获取经过验证的可见文本或选区。

### Courses、Little Tutor 与 Ask Questions

Learning Space 现在将对话组织为 Courses，支持置顶、归档、移动、筛选和嵌套的导师线程控制。在对话中选中文本即可打开独立的、基于来源的 Little Tutor 线程，该线程归属其父线程并继承所属课程。**Ask Questions** 先以一张上下文感知的澄清卡片开始，再根据回答完成原始请求。

### 知识库跟踪文档站点

除 GitHub 仓库外，知识库还可注册文档 URL，并显式限定爬取深度和页面数量。按需同步会先对新增、变更和删除的页面做哈希比对，再重新建立索引。**Serply** 新增网页、新闻和学术搜索模式，兼容的 OpenAI Responses 模型可使用其原生服务端网页搜索。

### 共享 Books 保持学习私密

管理员可按用户将规范 Books 共享为 `none`、`read` 或协作 `edit`，单独控制个人 Book 的创建，并保持仅管理员可删除。进度、书签、测验作答、Page Chat 链接和可审阅的 Learning Capture 收件箱均按读者保持私密。共享编辑使用修订检查，过期的编辑器会刷新，而不会覆盖协作者的修改。

### 阅读、辅导与长会话可靠性

阅读器大纲和顺序导航保持位置，格式错误或超时的 Reading 扩展保持隔离，注释锚点能在标题和重排后存活。Selection Tutor 的来源依据和测验追问保持持久；Mastery 拒绝纯文本测验回退，并区分澄清与作答；对话压缩保持在有界预算内，解码后的不可见 Unicode 控制字符不再泄漏到显示中。

### 提供方与平台加固

llama.cpp 报告其真实上下文窗口，Kimi 编码模型获得兼容参数，LightRAG 保留非对称嵌入上下文，Codex TLS 失败保持 fail-closed。Windows 运行器、工具、路径和测试兼容性得到广泛清理。发布工作流现在会在误导性或非版本标签取代最新稳定发布之前将其拒绝。

## 升级说明

`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需手动迁移或重建索引。

- **共享的管理员 Books 默认无访问权限。** 现有个人 Books 保持私密且不变。在多用户部署中，打开 `/admin/users`，展开用户，仅为其应阅读或编辑的管理员 Books 配置 **Book access**。
- **共享编辑为乐观模式。** 若其他编辑者先推进了 Book 修订，请刷新 Book 并重新应用更改；DeepTutor 不会静默覆盖较新的修订。
- **网页和 GitHub 来源仍为可选启用。** 现有知识库在你注册来源并运行同步之前保持不变。
- **搜索仍为可选。** 在 `deeptutor init` 期间选择 Serply，或稍后在 **Settings → Models → Search** 下配置；现有搜索设置继续有效。
- 英文和中文指南已在 [deeptutor.info](https://deeptutor.info/) 同步更新。
