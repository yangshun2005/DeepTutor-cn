# DeepTutor v1.5.10 发布说明

**发布日期：** 2026.08.07

[v1.5.9](ver1-5-9.md) 讲的是提供商；这一版讲的是它们底下的路径撑不撑得住——一次批量上传卡住了其他所有请求，一个知识库列表重扫了每个索引，一次工具调用没带参数就派发、还一直重试到预算耗尽。另外两处悄悄缺失的东西也补上了：账户可以登录自己的 Codex，模型的回复语言终于成了独立设置。直接升级——无需迁移，无需重建索引。

## 新增内容

### 每个账户都能登录自己的 Codex

一个 Codex token 授权的是某个人的 ChatGPT 套餐，所以该配置本来就不该可授予——但 OAuth 端点也仅限管理员，普通用户完全无路可走。现在他们可以自行登录：卡片位于 **Models → LLM**，创建的配置写入该用户自己的目录（`data/users/<uid>/settings/model_catalog.json`），绝不写入共享的管理员目录。授权解析在一处同时处理个人行和已分配行，因此选项列表、能力门控和选择校验不会互相矛盾——管理员查看某人的授权时，仍只看到自己分配的内容。合作伙伴被拒绝：合作伙伴是合成用户，放行它意味着替其所有者登录行事。

### 模型输出语言成为独立设置

**Settings → Appearance** 现在有两个独立开关。**界面语言** 覆盖导航、设置和状态文本；**模型输出语言** 设定聊天和能力回复的默认语言，此前只能通过提示词引导。拆分前写入的 `interface.json` 会把单一的 `language` 继承到两个字段，所以在选择之前一切不变。读取这些设置的会话前引导现在也是公开的——`/login` 和 `/register` 之前一直是英文，因为匿名读取命中了受门控的路由并返回 401；它只返回主题和语言，且本浏览器中做出的选择仍然优先。

### 无参数的工具调用被拒绝，而非执行

在工具面很大、历史很长时，提供商会间歇性发出 `arguments` 为空的原生函数调用，即使 Schema 标记了必填字段。调用照样被派发，于是由*工具*来拒绝——`exec` 抛出 "requires a non-empty command"，`write_note` 回答 "Unknown mode ''"——两者读起来都不像"缺少参数"，模型便重复发出同样的畸形调用，直到循环预算耗尽。派发前的守卫现在会指明缺失的参数及其可接受值（含枚举），把这一过程变成一轮自我纠正。规则保持严格：有默认值的参数不算必填，空集合不予处理，服务端注入的 kwargs 视为已提供。

### 上传和知识库列表不再占用事件循环

批量上传文件会在整个批次期间卡住其他所有请求——包括聊天 WebSocket：分块写入、zip 解压和逐文件 PocketBase 上传都在异步上下文中内联执行，后续的暂存步骤又放在 `async def` 后台任务里，而 Starlette 是在事件循环*上*等待它，而非在线程池中。两者现在都在工作线程中运行。另外，构建一次知识库列表响应会重新加载配置并逐项重扫每个索引；现在复用一份协调后的快照——58 KB 的只读列表约 2 秒完成，而不是让代理超时。

### Deep Research 直接读取已连接的 Obsidian 库

当选中的知识库是已链接的 Obsidian 库时，研究循环不再针对不存在的索引自动挂载 `rag`。它改为挂载三个只读库工具——`obsidian_search` / `obsidian_read` / `obsidian_list`——在服务端注入库路径（覆盖模型提供的任何值），将其结果视为可引用，使证据进入引用管理器和最终报告，并换入 Obsidian 专用的系统说明。已建索引的知识库和无知识库的运行不受影响。

### 服务端后端地址统一为 IPv4 回环

在双栈主机上 `localhost` 优先解析为 `::1`，而 uvicorn 绑定的是 `0.0.0.0`——仅 IPv4——于是每个重写后的 `/api/*` 请求都连接失败。启动器先修好了；Docker 入口的 `render_environment` 和 `web/proxy.ts` 的最后兜底默认值仍保留主机名，现已同步。

### 其他

- **Escape 会停止流式 Partner 回复**，且仅此而已：监听器在任何对话框角色浮层挂载时退出，因此关闭模态框或选择器不再杀掉其背后的回答。
- **视觉能力覆盖**现在按厂商前缀匹配 `claude-`（此前没有任何键以 `claude-4` 开头，所以那个键匹配不到任何东西），并识别 **Kimi K3** 和 **Qwen3.8-Max**。
- **Codex 上下文窗口元数据**在目录往返中得以保留，不再被丢弃。
- **编辑消息不再与其后的刷新竞争**，乐观气泡不再闪回。
- **`deeptutor-cli` wheel 重新打包了各 agent 的提示词 YAML**——此前一个都没有，导致提示词加载失败，且空结果在进程生命周期内被缓存。未命中也不再缓存，因此启动后才出现的资源会在重试时被拾取。

## 升级说明

`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无 Schema 变更，无需重建索引，无需迁移。

- **模型输出语言默认沿用现有界面语言。** 拆分是继承而非重置——若希望回复语言与 UI 不同，请在 **Settings → Appearance** 中显式设置。
- **非管理员 Codex 登录默认开启。** 每个账户的配置留在自己的目录中，管理员和其他用户均不可见；普通用户登录的任何内容都不会出现在共享模型列表或授权编辑器中。
