# DeepTutor v1.5.6 发布说明

**发布日期：** 2026.07.29

这是 [v1.5.5](ver1-5-5.md) 的后续版本，补完了它开启的工作：它引入的 Codex 登录现在能在远程或容器化部署上真正完成，对合作伙伴和非管理员同样适用。此外，知识库可以指向你已在腾讯 IMA 中维护的文库，对话生成的文件不再藏在对话记录里，日文书籍也不会再返回中文测验。直接升级——无需迁移。

## 新增内容

### 连接腾讯 IMA 文库

知识库现在可以指向你在 [腾讯 IMA](https://ima.qq.com/) 中维护的文库，而不是由 DeepTutor 构建的索引。它完全沿用 `lightrag-server` 的形态：不复制任何内容，也不在本地存储任何内容——文档在 IMA 中添加，检索调用 IMA 的 OpenAPI，对话循环仍负责写入答案。凭据（`client_id` + `api_key`）和文库 id 按知识库分别保存，因此在共享部署中，每个用户通过自己的 IMA 账户检索，而不是共用一个全局密钥；连接过程自包含，无需先填写设置界面。连接时会探测一次文库，因此 id 输错会在连接时报错，而不是在之后每次查询时静默失败。

### 生成的文件，随时可以再找到

导师生成的文件此前只能通过产生它的那一个助手气泡访问，想再找到一份演示文稿或电子表格就得翻对话记录。活动面板现在把对话*生成*的内容与你*上传*的内容分开：生成的文件在附件上方有独立卡片，显示大小，悬停标题显示文件在数据根目录下的位置。各行复用现有的在查看器中打开路径。

### 可完成的远程 Codex 登录

v1.5.5 发布了 OpenAI Codex OAuth，但有一个注意事项——在远程机器上，请从服务器端登录。该注意事项已取消。浏览器的 `localhost` 和服务器的 `localhost` 是不同的机器，因此仅靠反向代理永远无法承载回调；DeepTutor 现在只将确切的回调路径通过 Web 源转发到会校验 state 的代理，设置卡片和 CLI 会打印真实的回调地址、SSH 隧道命令、明确的授权操作，以及一个能在页面刷新后继续的倒计时（[#716](https://github.com/HKUDS/DeepTutor/issues/716)）。

两个后续修复让部署上的其他所有人也能使用。回调通过 OAuth `state` 传递——这是本进程为一次登录生成的密钥，以常量时间比较——而不是通过请求的用户，因为浏览器经由你自己的隧道到达，不携带会话 cookie；没有这一点，远程登录会对每个非管理员返回 `login_not_active`。合作伙伴对话现在将 Codex 凭据解析到所有者根目录，而不是合作伙伴的合成工作区，因此与合作伙伴聊天不再失败并提示“Sign in to Codex before using this model”（[#713](https://github.com/HKUDS/DeepTutor/issues/713)）。

监听器仍绑定到回环地址，端口 `1455` 和 `1457` 从不对外发布，回调响应从不回显 code 或 state，PKCE 和令牌交换保持不变。

### 每种语言保持自己的语言

`parse_language()` 以裸 `return "zh"` 结尾，因此 ja/ko/fr/de/ru/ar 全部解析为中文——这就是日文书籍返回中文测验的原因（[#712](https://github.com/HKUDS/DeepTutor/issues/712)）。它现在委托给现有的规范化器，并透传未知代码；两个假定答案为 zh 或 en 的回退链也随之调整：提示词尝试 `[code, base locale, "en"]`，因此 `zh-tw` 复用中文文件，`ja` 落到英文而非中文。

### 其他修复

- 书籍创建和块重新生成通过 WebSocket 运行，而不是可能被代理超时的请求；spine 合成和 Visualize 的分析阶段使用非流式调用，因此单章回退或代码块截断不再发生（[#707](https://github.com/HKUDS/DeepTutor/issues/707)）。这三者现在都经由 agent 接缝路由，恢复了直接工厂调用所丢弃的图片附件、跟踪元数据和按 agent 路由。
- 在全新源码检出上运行 `deeptutor start` 会为你安装 `web/node_modules`，而不是因缺少模块错误而崩溃（[#710](https://github.com/HKUDS/DeepTutor/issues/710)）。
- 管理员用户管理、退出登录、确认对话框和 toast 已本地化，因此将 UI 切换为中文后，账户管理不再显示英文（[#718](https://github.com/HKUDS/DeepTutor/issues/718)）。
- 服务懒加载器使用字面导入路径（[#717](https://github.com/HKUDS/DeepTutor/issues/717)）——行为中性，但使模块图可静态分析。

## 升级说明

从 v1.5.5 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移，无 Schema 或配置变更。

- **远程 Codex 登录现在使用 SSH 隧道**，v1.5.5 中在服务器上运行 `deeptutor provider login openai-codex` 的建议不再是唯一路径。DeepTutor 会打印确切的 `ssh -N -L …` 命令；只运行与其报告的回调端口匹配的那一条，并注意该命令中的 `3782` 是示例——请替换为 SSH 主机回环上实际监听的 Web 端口。
- 腾讯 IMA 知识库需要来自 [ima.qq.com/agent-interface](https://ima.qq.com/agent-interface) 的 `client_id` 和 API 密钥，以及文库 id。文档在 IMA 中添加，而不是通过 DeepTutor。
