# 🔧 DeepTutor v0.5.1 发布说明

**发布日期：** 2026.01.18

大家好！我们刚刚发布了 v0.5.1！

## ✨ 亮点

### 📄 RAG-Anything 支持 Docling

新增了使用 **Docling** 作为文档解析器的 RAG-Anything 替代初始化方式：
- 适用于本地环境不适合 MinerU 的用户
- 提供轻量级的文档处理替代方案
- 相同的多模态图能力，不同的后端

### 📝 日志系统优化

重构了日志系统以便更好地管理：
- 改进了所有模块的日志输出控制
- 更好的结构化日志适配器
- 增强了控制台、文件和 WebSocket 处理器

### 🐛 Bug 修复与代码改进

- 优化了多个模块的代码结构
- 修复了若干影响用户体验的 Bug
- 改进了 CI/CD 工作流，增加 Python 3.10/3.11 矩阵测试
