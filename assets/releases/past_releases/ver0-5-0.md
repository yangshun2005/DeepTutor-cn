# DeepTutor v0.5.0 发布说明

**发布日期：** 2026.01.15

我们很高兴宣布 DeepTutor v0.5.0！本次发布带来**统一服务配置**、**灵活的 RAG 流水线选择**，以及多个模块的**重大 UI/UX 改进**。

> **稳定性更新：** 本次发布修复了多个环境配置和稳定性问题。建议所有用户拉取最新版本！记得更新你的 .env 文件！

> [!TIP]
> **征集 Issue：** 欢迎反馈！如果遇到 bug 或有功能需求，请[提交 Issue](https://github.com/HKUDS/DeepTutor/issues)！如需提交 PR，请查看我们的[贡献指南](https://github.com/HKUDS/DeepTutor/blob/main/CONTRIBUTING.md)。

## 快速概览

- **配置** — 重构配置逻辑，LLM/Embedding 设置更顺畅。后端密钥不再暴露给前端。新增更多搜索提供商。
- **RAG 流水线** — 按知识库选择不同流水线：LlamaIndex（直连）、LightRAG（图）、RAG-Anything（多模态图）。
- **问题生成** — 统一 BaseAgent 架构，UI 更直观。
- **首页** — 将聊天记录保存到笔记本。
- **侧边栏** — 拖拽排序 + 可自定义左上角标签。
- **其他** — 多项 bug 修复和稳定性改进。

## ✨ 亮点

### 统一配置系统

全面重新设计 LLM、Embedding、TTS 和搜索服务的配置管理：

**核心特性：**
- **基于环境的密钥**：敏感 API 密钥存放在 `.env`，配置在 UI 中管理
- **`{"use_env": "VAR_NAME"}` 语法**：引用环境变量而不在前端暴露
- **按服务独立激活配置**：每个服务（LLM、Embedding、TTS、搜索）维护各自的激活配置
- **无缝切换提供商**：在前端添加新提供商，无需触碰后端密钥


**新增搜索提供商：**
| 提供商 | 描述 |
|:---|:---|
| Tavily | AI 原生搜索 API |
| Exa | 神经搜索引擎 |
| Jina | 基于 Reader 的网页搜索 |
| Serper | Google SERP API |

### RAG 流水线选择

根据速度/质量需求，为每个知识库选择最优 RAG 流水线：

| 流水线 | 索引类型 | 适用场景 | 速度 |
|:---|:---|:---|:---|
| **LlamaIndex** | 向量（直连） | 快速搭建、简单文档 | 最快 |
| **LightRAG** | 知识图谱 | 通用文档、文本为主 | 快 |
| **RAG-Anything** | 多模态图 | 学术论文、含图表/公式的教材 | 全面 |

### 问题生成重构

重构问题生成模块，统一 Agent 架构：

**后端变更：**
- 迁移至与其他模块一致的 `BaseAgent` 模式
- 新增专用 Agent：`RetrieveAgent`、`GenerateAgent`、`RelevanceAnalyzer`
- 单次生成 + 相关性分类（不再迭代验证循环）
- 改进 JSON 解析，支持提取 markdown 代码块

**前端改进：**
- 实时进度面板，带阶段指示器
- 日志抽屉，用于调试生成过程
- 更简洁的问题卡片布局，支持提交答案
- "添加到笔记本"集成

### 首页增强

**保存聊天到笔记本：**
- 聊天界面新增"保存到笔记本"按钮
- 自动将对话格式化为 markdown
- 保留用户查询和助手回复，并标注角色

### 侧边栏自定义

**拖拽导航：**
- 在分组内拖拽排序侧边栏项目
- 拖拽过程有视觉反馈
- 顺序持久化保存到用户设置

**可自定义描述：**
- 点击编辑侧边栏描述标签
- 个性化你的工作区标识

## 📦 变更内容

### 核心基础设施

- 新增 `deeptutor/services/config/unified_config.py` — 集中式配置管理器
- 新增 `deeptutor/api/routers/config.py` — 所有服务配置的统一 REST API
- 重构网页搜索，支持多提供商（`deeptutor/services/search/`）
- 通过 LLM 错误框架增强错误处理

### RAG 系统

- 实现 `LlamaIndexPipeline`，含自定义 embedding 适配器
- 实现纯 `LightRAGPipeline`，含完整初始化
- 知识库创建/上传时支持选择流水线（PR #129）
- `deeptutor/services/rag/factory.py` 中的工厂模式用于流水线管理

### 问题生成

- 重构 `AgentCoordinator`，引入专用 Agent
- `deeptutor/agents/question/agents/` 中新增 `RetrieveAgent`、`GenerateAgent`、`RelevanceAnalyzer`
- 移除迭代验证循环，加快生成速度
- 新增 `useQuestionReducer` Hook 用于前端状态管理

### 前端更新

- `web/app/settings/page.tsx` — 全面重建，统一配置 UI
- `web/app/question/page.tsx` — 新面板，带进度跟踪
- `web/app/page.tsx` — 新增"保存到笔记本"功能
- `web/components/Sidebar.tsx` — 拖拽 + 可编辑描述
- `web/components/AddToNotebookModal.tsx` — 可复用的笔记本集成
