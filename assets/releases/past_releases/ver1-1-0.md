# DeepTutor v1.1.0 发布说明

**发布日期：** 2026.04.15

## 亮点

### LaTeX 块级数学公式解析重构
重写了 `normalizeEditorMdInlineMath` 流水线，正确处理宽松的块级数学公式——即内容被单独一行上的单个 `$` 分隔符包裹的情况（如 `$\n\\frac{a}{b}\n$`）。新增 `looksLikeLatexBlock` 启发式规则，扫描被包裹的行中是否包含 LaTeX 特有标记（`\\command`、`\\\\`、`_`、`^`、`&`），在适当时将分隔符提升为 `$$…$$`，同时不影响非 LaTeX 用途的美元符号。此外收紧了单行 `$$…$$` 正则，要求末尾有 `$` 锚点，避免过度匹配。

### LLM 诊断探针 — `agents.yaml` 配置
将 LLM 探针的 `max_tokens` 设置从 `LLM_TEST_MAX_TOKENS` 环境变量迁移到 `agents.yaml` 中的 `diagnostics.llm_probe.max_tokens`，与现有 agent 参数体系保持一致。环境变量方式及其 Docker/`.env.example` 条目已移除，改用统一配置加载器（`get_agent_params("llm_probe")`）。

### LLM 工厂中的额外请求头转发
`llm_complete` 和 `llm_stream` 现在通过 kwargs 接受调用方传入的 `extra_headers`，并与提供方级别的请求头合并，不再静默丢弃或重复传递。修复了 agent（如 `NotebookSummarizeAgent`）转发自定义网关请求头时触发的 `TypeError: multiple values for keyword argument 'extra_headers'` 崩溃。

### SaveToNotebookModal UUID 修复
该模态框现在从 `/api/v1/notebook/list`（基于 UUID）获取笔记本，而非 `listCategories()`（旧版问题笔记本 API 的整数分类 ID）。这解决了 Issue #301：Co-Writer 及其他非测验类保存会静默失败，因为数字分类 ID 永远无法匹配任何笔记本 UUID。

### Docker + 本地 LLM 指引
在 `.env.example`、`.env.example_CN`、`docker-compose.yml` 和 `docker-compose.ghcr.yml` 中新增了醒目的文档块，说明当 LLM/嵌入服务器运行在宿主机上时如何使用 `host.docker.internal`——涵盖 macOS/Windows Docker Desktop 以及 Linux 局域网 IP / `--network=host` 替代方案。

### 测试套件扩展
新增 5 个测试模块（153 + 107 + 114 + 193 + 102 行），覆盖 LaTeX 分隔符转换与块级数学公式提升（`web/tests/latex.test.ts`）、笔记本路由 UUID 校验（`tests/api/test_main_notebook_router.py`）、`NotebookSummarizeAgent` 额外请求头转发（`tests/agents/notebook/`）、LLM 探针 `agents.yaml` 集成（`tests/services/config/test_llm_probe_config.py`），以及 LLM 工厂中 `extra_headers` 的去重/合并（`tests/services/llm/test_factory_provider_exec.py`）。
