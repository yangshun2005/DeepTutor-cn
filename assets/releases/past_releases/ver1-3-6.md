# DeepTutor v1.3.6 发布说明

**发布日期：** 2026.05.03

v1.3.6 重点是在 DeepTutor 中显式化模型路由。用户可在聊天和 TutorBot 流程中选择已配置的 LLM 配置档，运行时服务解析这些选择时不会泄露提供商密钥；当持久化嵌入无效时，RAG/知识库索引处理更具防御性。

## 亮点

### 基于目录的模型选择

- **聊天可指定已配置的模型** - 统一聊天轮次现在通过 WebSocket 载荷、会话偏好、轮次快照和重新生成流程携带 `profile_id` 和 `model_id` 选择。
- **设置页暴露安全的 LLM 选项** - 新增的设置选项端点返回可直接展示的提供商/模型选项，同时从响应中省略凭据和连接密钥。
- **运行时模型覆盖按轮次限定作用域** - 所选配置档通过提供商目录为当前请求解析，不会将临时选择写回磁盘或更改全局默认值。
- **模型选择器 UI 共用** - 聊天和 TutorBot 界面使用相同的已配置模型选择器，带本地化标签和系统默认处理。

### TutorBot 模型控制

- **Bot 可持久化模型选择** - TutorBot 创建/更新流程现在接受 `llm_selection`，对照已配置目录进行校验，并与每个 bot 一起存储。
- **运行中的 bot 可重新加载其 LLM** - 更改 bot 的模型会更新活动 agent 循环，无需完全重启 bot。
- **近期 bot 历史更稳定** - TutorBot 历史组装现在按消息时间戳排序，并使用稳定的平局决胜规则，然后取最新上下文。
- **Bot 聊天路由切换更干净** - Web 聊天页面在切换 bot 时取消进行中的 bot 请求并重置瞬态推理状态。

### RAG 与知识可靠性

- **无效向量触发重建** - 当现有向量存储未通过嵌入校验时，重新索引不再将匹配的文档签名视为可复用。
- **完整重建使用新版本目录** - 完整知识库重建写入新的扁平索引版本，同时保留失败的旧存储以供检查。
- **RAG 工具日志可流式发送给客户端** - 当事件接收器可用时，检索运行可将捕获的 INFO 级过程日志作为原始工具事件转发。
- **知识健康检查识别坏嵌入** - 无效的持久化向量会更早暴露，而不是产生不透明的搜索失败。

### 提供商与启动修复

- **OpenAI Responses 令牌限制已规范化** - Responses API 调用现在将聊天风格的 `max_completion_tokens` 和 `max_tokens` 映射为 `max_output_tokens`，修复了 #437 中报告的较新 OpenAI 模型的 SDK 错误。
- **Azure 和 OpenAI 兼容路径共用映射** - 流式和非流式 Responses API 路由均使用相同的转换辅助函数。
- **启动端口来自 `.env` 和环境变量** - 设置和启动辅助函数现在围绕项目 `.env` 文件保持后端/前端端口行为一致，而非旧的运行时设置 JSON。

### Web 用户体验优化

- **技能名称保存前校验** - Skills 编辑器将名称 slug 化，内联标记无效输入，并防止大写字母、空格、下划线或其他不支持字符导致的静默 API 失败。
- **技能编辑器模态框在各主题下不透明** - 编辑器现在使用页面背景 token，避免半透明主题下文字透出。
- **空间导航更易浏览** - Space 迷你导航、笔记本、题库、技能和会话列表的间距已收紧，卡片和分隔线处理更清晰。

## 升级说明

- 希望显式模型路由的聊天和 TutorBot 客户端应发送 `llm_selection` 为 `{ "profile_id": "...", "model_id": "..." }`。省略则继续使用已配置的系统默认值。
- TutorBot 配置文件现在可包含 `llm_selection`。不含该字段的现有 bot 配置仍可加载，旧版 `model` 值仍可作为模型名称覆盖使用。
- 启动端口应在 `.env` 或进程环境变量（`BACKEND_PORT` / `FRONTEND_PORT`）中配置。旧的 `data/user/settings/env.json` 端口块不再作为启动端口来源。
- 含过期或无效持久化向量的知识库可能在下次重新索引时重建，即使文档签名未变。
- 技能名称现在规范化和校验为最多 64 个字符的小写 slug，使用字母、数字和连字符。
