# DeepTutor v1.4.9 发布说明

**发布日期：** 2026.06.19

这是 [v1.4.8](ver1-4-8.md) 的维护性后续版本，优化了设置，并将掌握练习接入题库。搜索设置现在只显示你的提供商实际使用的连接字段，连接配置可以重命名，并会按提供商自动命名，你在掌握路径中回答的问题会被记录以供回顾。直接升级——无需迁移。

## 新增内容

### 搜索设置只显示你的提供商使用的字段

设置 → 搜索现在会根据你选择的提供商调整连接字段。API 密钥类提供商（Brave、Tavily、Jina、Perplexity、Serper）只显示 API 密钥；SearXNG 只显示其 Base URL，并标记为必填；DuckDuckGo 和“none”完全不显示凭据。自定义或无法识别的提供商仍显示所有字段，因此提供商可能需要的任何内容都不会被隐藏。

### 重命名连接配置，按提供商自动命名

新建的连接配置现在会直接以提供商命名，旁边提供重命名控件。只要你没有输入自己的名称，切换提供商时配置会继续跟随提供商——一个“Brave”配置会变成“Jina”——但一旦你重命名，名称就归你所有，永远不会被覆盖。

### 掌握练习汇入你的题库

当 DeepTutor 在掌握路径中批改问题时，这次尝试——问题、你的答案以及是否正确——现在会记录到该会话的题库中。你在学习计划中进行的练习会与生成的测验并列，随时可以回顾。

### 修复与文档

- 设置导览的 **Tools** 步骤显示的是原始占位文本，而不是其标题和描述；现在中英文都能正确显示，并有测试防止导览步骤未翻译。
- README 及其翻译已针对当前 UI 更新——包括更新的界面导览、My Agents、知识中心以及最新截图。

## 升级说明

从 v1.4.8 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移，无需更改配置。
