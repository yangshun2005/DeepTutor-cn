# DeepTutor v1.4.7 发布说明

**发布日期：** 2026.06.18

本版本在 [v1.4.6](ver1-4-6.md) 基础上聚焦一件事：让本地编码 agent 成为 DeepTutor 可对话的对象。将运行在你机器上的 **Claude Code** 或 **Codex** 接入为知识源，聊天中即可实时咨询它。**My Agents** 升级为顶级入口，Partner 对话新增分支 / 恢复 / 删除，并支持可回放轨迹；EduHub 技能浏览器和语音提供商更加稳健。直接升级，无需迁移。

> **所有新功能均为可选启用。** 接入本地 agent 需要运行 DeepTutor 的机器上已安装 Claude Code 或 Codex CLI——在你主动连接之前，不会检测或启动任何东西。**My Agents** 从 `/space/agents` 移至顶级 `/agents`（内容不变，换了位置）。现有数据原样加载，无需迁移。

## 新增内容

### 已连接 Agent——咨询本地 Claude Code / Codex

现在可以将知识库指向**你自己机器上运行中的 agent CLI**，并在聊天中咨询它：

- DeepTutor 检测已安装的 **Claude Code** 或 **Codex**，将其接入为新的 `subagent` 知识源——仅指向该 CLI 及可选工作目录，不索引、不复制任何内容。
- 在输入框中选择该 agent，本轮对话即通过单个 `consult_subagent` 工具运行：模型向本地 agent 提问，实时观察其运行流，在一轮预算内来回交互，最后以自己的口吻回答你。
- 在 `/settings/agents` 配置各后端。

### My Agents 升级为顶级入口

**My Agents** 中心从学习空间移出，成为独立入口 `/agents`，分两部分：你已**连接**的实时 agent（见上），以及你已**导入**为可恢复 agent 的 Claude Code / Codex 聊天记录。

### Partners：分支、恢复与可回放轨迹

Partner 对话在 IM 和 Web 两端都更稳健：

- 新增斜杠命令——`/branch`、`/stop`、`/sessions`、`/resume`、`/delete`——与 `/help`、`/new`、`/status`、`/history`、`/tool` 并列。
- Web 端 Partner 聊天现在会持久化每轮的思考/工具轨迹，并在重新打开对话、切换会话或分支时**水合**回可折叠活动面板——与产品聊天一致。
- 对话拥有**自动生成的真实标题**，并可在任一端分支、恢复或删除。
- 内置工具现在可按 Partner 配置，与可切换的系统工具并列。

### 更稳健的 EduHub 与语音

**EduHub** 技能浏览器现为完整的应用内目录——导入前可搜索和预览镜像仓库技能——新增 `[EduHub]` Issue 模板，将镜像仓库的 bug 报告路由到主仓库。**语音**方面，提供商现在会返回带状态码和响应体的 HTTP 错误，而非笼统的失败；STT 接受原始 PCM 流（服务端转换为 WAV）。

## 升级说明

- 从 v1.4.6 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移。
- 已连接 Agent 需要运行 DeepTutor 的主机上已安装 Claude Code 和/或 Codex CLI——只会检测，不会替你安装。
- [deeptutor.info](https://deeptutor.info/) 的文档仍在追赶近期版本，稍后将更新。
