# DeepTutor v1.3.8 发布说明

**发布日期：** 2026.05.08

v1.3.8 将 DeepTutor 的可选多用户模式纳入主线发布。本地单用户安装保持不变，同时新增带身份认证的共享部署，支持隔离的用户工作区、管理员管理的访问权限，以及更清晰的部署指引。

## 亮点

### 多用户工作区

- **身份认证可为共享部署把关** - 启用 `AUTH_ENABLED` 后增加登录、注册、JWT 会话和首个用户成为管理员的流程。
- **每个用户的数据相互隔离** - 普通用户在 `multi-user/<uid>/` 下工作，拥有独立的聊天历史、记忆、笔记本和知识库；管理员保留主工作区。
- **管理员授予访问权限** - `/admin/users` 允许管理员创建用户，并分配允许的模型配置、知识库、技能和复制的空间，且不暴露 API 密钥。

### 更安全的运行时边界

- **知识与 RAG 保持作用域隔离** - 已分配的知识库带徽标显示，非管理员的 RAG 调用不再静默回退到管理员数据。
- **模型路由遵循授权** - 非管理员聊天轮次使用已分配的模型配置，若无可用 LLM 则提前失败。
- **用户设置经过脱敏** - 非管理员设置仅显示主题、语言和模型摘要，提供商密钥和端点仍仅管理员可见。

### 部署与 UI

- **前端认证路由已包含** - `/login`、`/register`、认证感知中间件、登出控件和管理员导航已接入 Web 应用。
- **多用户文档已升级为一等公民** - README 及各语言译本记录了安装配置、工作区布局、审计日志、环境变量和生产环境注意事项。
- **可选 PocketBase 仍有文档说明** - PocketBase 仍可作为 sidecar 方式使用，但真正的多用户部署应留空 `POCKETBASE_URL`，改用内置的 JSON/SQLite 后端。

## 测试

- 新增多用户测试，覆盖身份迁移、首个管理员注册、授权、设置限制、作用域内的界面偏好、技能访问和 RAG 回退防护。
- 新增状态脱敏覆盖，确保非管理员用户不会收到提供商模型或搜索端点详情。

## 升级说明

- 现有本地安装保持单用户模式，除非设置 `AUTH_ENABLED=true`。
- 真正的多用户部署需设置 `AUTH_ENABLED=true`，保持 `POCKETBASE_URL` 为空，通过 `/register` 创建首个管理员，并在普通用户开始聊天轮次前分配模型。
- 新的部署状态存储在 `multi-user/` 下；升级共享实例前请同时备份 `data/` 和 `multi-user/`。
- 多 Worker 部署应谨慎引导首个管理员，因为首个用户提升受进程内锁保护。
