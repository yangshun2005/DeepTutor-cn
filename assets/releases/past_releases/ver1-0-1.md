# DeepTutor v1.0.1 发布说明

**发布日期：** 2026.04.10

## 亮点

### 基于 Chart.js/SVG 渲染管线的可视化能力
新增 **Visualize** 能力，可将自然语言数据描述转换为交互式 Chart.js 或内联 SVG 可视化。后端运行三阶段 Agent 管线（分析 → 代码生成 → 审查），支持中英双语提示词。前端新增两个组件——`VisualizeConfigPanel` 用于请求配置，`VisualizationViewer` 用于渲染——已接入工作区首页和聊天输入框。

### 测验重复问题防护与生成历史
通过在 Generator 管线中引入专用的 `previous_questions` 参数，修复了测验题目重复的问题，该参数与对话 `history_context` 清晰分离。`MAX_PREVIOUS_QUESTIONS=20` 上限确保提示词大小有界，语言标签移至 YAML 模板中，避免跨语言环境混用。

### o4-mini 及未来 o 系列模型支持
扩展了 LLM 配置中的 o 系列正则，以识别 `o4-mini` 及未来 o 系列模型标识符，确保正确设置 `max_completion_tokens` 而非不支持的 `max_tokens` 参数（关闭 #274）。

### 服务器日志改进
- 抑制了 uvicorn WebSocket 连接/断开时刷屏的日志，减少服务器输出噪音。
- 新增选择性 HTTP 访问日志中间件，仅记录非 200 响应，在保留可操作错误可见性的同时减少日志噪音。
- 为不支持结构化输出的提供商新增 MiniMax 模型覆盖（`supports_response_format: false`）。
