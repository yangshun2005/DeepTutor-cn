# DeepTutor v1.6.7 发布说明

**发布日期：** 2026.09.11

v1.6.7 是一个修复版本，几乎完全由社区报告及对应的 Pull Request 组成——本次合并了十九个。贯穿其中的一条主线是推理模型。一本书生成后只剩一个空章节、一次测验完全没有生成题目、章节正文里混入了模型自己的草稿内容，这三者其实是同一个故障的三种表现——token 预算被隐藏思考耗尽，答案没有余量，也不报错。可直接升级——无需迁移。

## 新增内容

### 书籍不再只返回一个空章节

书籍生成在配置层不认识的名称下请求 token 设置，因此在打开 `agents.yaml` 之前就返回了硬编码的 4096——用户无法调高这个预算，而推理模型可能把它全部花在隐藏 token 上。空响应随后被解析为空对象，降级为一个占位章节；预算中途耗尽则产生另一种报告中的形态：所有章节都在，但目标为空。

书籍现已接入配置映射，初始值为 12000；若某轮返回时缺少所请求的键，则以更低的推理强度重试一次。该重试此前仅用于块写入器；现在四个流水线阶段共用它。

### 模型的草稿内容不再传给读者

非流式路径在答案为空时会把模型的推理内容当作答案返回——流式路径明确禁止了同样的行为，同一决策在两条代码路径上自相矛盾。另外，显式的“不思考”请求现在会收窄为各模型实际接受的取值：`gemini-3` 和 `gemini-2.5-pro` 对 `none` 返回 HTTP 400，而面向读者的书籍块请求的正是该值。

### 思考模型跨轮保留推理内容

将某轮的 `reasoning_content` 回放给提供商，此前以模型名包含 `deepseek` 为条件。模型名并不是提供商宣告其方言的方式——火山引擎 Ark 使用端点 id，而豆包、GLM、Qwen 和 Kimi 的思考模型各有各的标识。新的一轮回放历史时它们全部失败，而同一轮内则正常。现在的判断条件是提供商是否发送了该字段。

### 测验不再静默地不生成任何内容

计划步骤在其流水线中 token 预算最紧，而思考被截断的计划返回的空字符串与模型无话可说时相同。零模板意味着零题目——且不报错。现在两种情况可区分，预算不足的计划会以更低强度重试，预算也不再是异常值。

### 工具失败时会说明原因

“执行 rag 时发生未知错误。”在传给模型的过程中替换了真实原因，涉及聊天、研究和提问。现在原因随消息一同传递。这覆盖了所报告的情况：已停止的本地嵌入服务此前不可见——适配器一直会指明端点和补救方法，但文本在上层被丢弃了。自托管端点拒绝连接时，现在也会说明是两种情况中的哪一种——没有服务在监听，还是容器的 `localhost` 并非运行模型的机器。

### 公式在学习者阅读处正常渲染

掌握度问题卡片、`ask_user` 卡片和推理轨迹将 `$G_t = R_{t+1} + \gamma G_{t+1}$` 显示为原始文本。轨迹最严重：一个守卫将其排除在富渲染器之外，导致该渲染器自己的轨迹分支自三月起不可达。现在是否渲染数学公式由内容决定，而非由界面决定，因此不含数学公式的气泡仍走轻量路径。

### 卡片可以正常提交

没有选项的掌握度问题从从未渲染的字段读取答案，导致提交按钮永久禁用。而停在 `ask_user` 卡片上的一轮可能一直占用会话，却没有存活的对象来回答它——之后所有消息都被拒绝。两部分均已修复：收到回复时会回收被遗弃的一轮；制造这些行的终态检查（它只接受 `running`，从不接受等待人工的一轮）不再如此。

### 阅读、可视化、导入

沉浸式阅读现在附带 PDF.js 解码器资源，JPEG 2000 和 JBIG2 页面图像不再显示为空白。GeoGebra 在求值前拒绝已知致命的命令模式，并暴露此前被吞掉的失败；图像分析不再在到达模型之前就崩溃。Codex 历史导入读取当前的 rollout 格式，Codex 为自己注入的轮次——插件清单及类似内容——不再成为你的第一条消息或对话标题。

### 值得提及的较小修复

流式提供商错误现在会抛出，而不是作为助手答案投递。API 密钥池在配置解析器中得以保留。`read_skill` 区分文件缺失与技能缺失，而不是都报告为“未找到技能”。命令 id 在纯 HTTP 部署上可用，那里 `crypto.randomUUID` 为 undefined。当路由器不支持任一模态对时，图像生成仅以图像重试。研究工具的超时和重试设置现在真正生效——默认值为停滞提供商的上限，而非慢速工具就会触发的值。设置就绪状态对只读用户渲染，聊天可恢复为所附 PDF 虚构的工具调用，Watching 转录跟随当前提示而不是将其推出屏幕。

## 升级说明

运行 `pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移。

- **书籍的 token 预算现在可达。** 它位于 `agents.yaml` 的 `capabilities.book` 下，初始值为 12000。此前为 4096 且不可达，因此书籍默认获得显著更长的输入。
- **研究工具策略默认值已变更**——超时 60s → 240s，重试 3 → 0。研究工具天生较慢，而重试会再次支付完整超时。如果你在较早版本下保存过研究设置，已存储的值仍然优先；清除它们以采用新默认值。
- **已知问题：** 本次升级前被搁置的 `ask_user` 轮次仍可能占用其会话。创建它们的路径已关闭，但现有行尚未在启动时清理——该清理将在后续版本中提供。
