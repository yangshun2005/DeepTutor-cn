# DeepTutor v1.4.6 发布说明

**发布日期：** 2026.06.17

_提示：文档仍在跟进本次发布，部分页面可能尚未反映以下全部内容。_

这是在 [v1.4.5](ver1-4-5.md) 基础上的大规模整合版本，围绕其涉及的四个界面组织：**学习空间**成为真正的仪表盘，**知识中心**新增检索引擎和外部挂载，**设置**开放文档解析、语音和媒体生成，平台收紧了按用户访问控制。直接升级——无需数据迁移。

> **一处行为变更；其余均为可选启用。** 未分配模型的用户现在会在 UI 和服务端门禁中同时看到 LLM 能力被锁定——管理员永不受门禁限制，因此只需确保每个用户都分配了模型。新的知识中心引擎（GraphRAG、PageIndex）以及文档解析 / 语音 / 图像视频服务在配置前均处于关闭状态；默认不会运行或下载任何新内容。无需数据迁移：现有空间、记忆和知识库按原样加载。

## 新增内容

### 学习空间

**空间**现在是学习仪表盘，将你的工作汇聚一处，周边界面也随之完善：

- **我的智能体** — 将本地 Claude Code / Codex 聊天记录导入为可继续对话的智能体（`/space/agents`）。被引用的对话记录会获得客观简报和第三方视角，因此导师会叙述它，而不是扮演你。
- **记忆**提升为独立的一级入口（`/memory`），不再埋没在工作区中，L1/L2/L3 视图保持不变。
- **伙伴**对话现在与聊天走同一管道流入记忆。
- 在 `/space/skills` 内联从 **EduHub** 安装社区技能。

### 知识中心

`/knowledge` 重建为**知识中心**控制台——引擎卡片仅作为入口，配置移入各引擎的详情页：

- 新检索引擎加入 LlamaIndex：**GraphRAG**（microsoft/graphrag）、**PageIndex**（云端推理检索）以及完善的 **LightRAG** 后端——按知识库选择。
- **链接知识库** — 将知识库指向已构建的索引文件夹作为只读挂载，完全跳过摄取。
- **Obsidian** — 连接实时仓库作为智能体知识能力，可直接读写笔记。

### 设置

新增可配置服务，各有独立设置页，配置前均关闭：

- **文档解析** — 可插拔解析层（MinerU、Docling、MarkItDown），带内容寻址缓存（`/settings/document-parsing`）。MinerU 新增云端/本地双后端（`/settings/mineru`），现可提取题型、难度和答案。
- **语音** — 回复的朗读按钮，支持三态自动播放（TTS）；输入框麦克风用于听写（STT），位于 `/settings/tts` 和 `/settings/stt`。
- **图像与视频生成** — 可配置模型目录接入聊天工具（`/settings/image`、`/settings/video`）。
- 设置导航围绕扩展后的界面重建。

### 其他

- **按用户访问门禁** — 未分配模型的用户 LLM 能力被锁定，侧边栏锁与服务端门禁始终一致。
- **Solve** 重建为聊天循环上的能力，带每步门禁和运行中失败回退，强制优雅结束而非整轮失败。
- **登录**接受用户名（不仅是邮箱），内联显示登录错误而非静默重载，并修复 `NEXT_PUBLIC_AUTH_ENABLED` 标志。
- **CLI** 新增 `deeptutor skill` 命令——浏览器登录以及发布/更新自己的技能。
- 上下文选择器统一到共享外壳并带实时预览，修复引用链接化导致 `$…$` 被破坏的数学公式渲染问题。

## 升级说明

- 从 v1.4.5 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移——现有数据按原样加载。
- 为每个用户分配模型以解锁其能力；管理员从模型目录管理。
- 新引擎和服务为可选启用：GraphRAG 需要额外依赖（`pip install 'deeptutor[graphrag]'`），文档解析需要 `deeptutor[parse]`，语音 / 图像 / 视频需要配置各自的模型目录。
