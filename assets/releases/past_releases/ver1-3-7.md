# DeepTutor v1.3.7 发布说明

**发布日期：** 2026.05.04

v1.3.7 聚焦思考模型兼容性、更清晰的知识库索引历史，以及更安全的 Co-Writer 编辑。它控制住各提供商特有的推理输出，同时让索引活动在 UI 中更易理解。

## 亮点

### 思考模型与网关兼容性

- **推理输出保持独立** — OpenAI 兼容提供商和 TutorBot 提供商将 `reasoning_content` 排除在可见回答文本之外，流式输出不再把内部草稿当作最终内容重放。
- **DeepSeek 思考可通过 `.env` 配置** — `LLM_REASONING_EFFORT` 已有文档说明，并通过解析器路径生效。用 `minimal` 禁用 DeepSeek 思考，用 `high` / `max` 启用。
- **自定义网关请求头得以保留** — 聊天和显式 LLM 调用继承配置文件的 `extra_headers`，修复了需要自定义请求头（如覆盖 `User-Agent`）的网关问题。
- **结构化生成更宽容** — 书籍块和问题构思现在能更可靠地处理带围栏、经修复、列表形或其他不完美的 JSON 输出。

### 知识索引可见性

- **索引活动被记录** — 创建、上传和重建索引流程现在会在知识元数据中存储 `last_indexed_at`、已索引文档数和索引操作。
- **进度载荷描述真实的索引变化** — 后端状态更新可区分仅元数据完成与实际向量索引更新。
- **知识 UI 显示索引历史** — 详情、设置和索引版本面板在可用时显示最新索引时间和文档数。

### Co-Writer 编辑安全

- **清空和模板操作先询问** — 替换非空草稿时，现在会先打开确认对话框，再清空或覆盖编辑器。
- **撤销更可靠** — 待处理的输入快照会在工具栏编辑前提交，编辑器快捷键支持 Ctrl/Cmd+Z、Shift+Cmd+Z 和 Ctrl/Cmd+Y。
- **工具栏控件更清晰** — 破坏性操作和模板操作现在有不同色调、焦点状态、标签和无障碍工具提示。

## 测试

- 新增 OpenAI 兼容提供商测试，确保服务和 TutorBot 路径中 `reasoning_content` 与可见响应内容保持分离。
- 扩展 LLM 工厂测试，覆盖继承的 `extra_headers`、继承的 `reasoning_effort` 和仅推理的流式行为。
- 新增知识管理器覆盖，验证仅在索引实际变化时记录 `last_indexed_*` 元数据。

## 升级说明

- 如需全局思考控制，请在 `.env` 中设置 `LLM_REASONING_EFFORT`。留空则让 DeepTutor 根据当前模型自动检测行为。
- 知识库元数据现在可能包含 `last_indexed_at`、`last_indexed_count` 和 `last_indexed_action`。
- Co-Writer 的清空/模板操作在用户离开当前草稿前可通过撤销恢复。
