# 🚀 DeepTutor v0.3.0 发布说明

**发布日期：** 2026 年 1 月 6 日

我们很高兴宣布 DeepTutor v0.3.0！本次发布聚焦于**开发者体验改进**、**CI/CD 自动化**和**简化本地部署**。

## ✨ 亮点

### 🏗️ 统一 PromptManager 架构

一次重大重构将 10+ 个 agent 模块中的所有提示词加载逻辑整合到集中式的 `PromptManager` 单例中：

- **全局缓存**，支持模块级失效，提升性能
- **语言回退链**（`zh → en`、`en → zh`），实现无缝 i18n 支持
- **符合 ISO 639-1 标准**——所有 `cn/` 提示词目录重命名为 `zh/`
- 移除冗余的 `_load_prompts` 方法和类级缓存，简化 agent 代码

### 🤖 GitHub Actions 与 CI/CD

引入自动化工作流，提升代码质量并简化部署：

| 工作流 | 描述 |
|:---|:---|
| `dependabot.yml` | 自动更新依赖（pip、npm、GitHub Actions、Docker） |
| `tests.yml` | 在 push/PR 时自动测试 |
| `docker-publish.yml` | 自动发布 Docker 镜像到 GHCR |

### 🐳 预构建 Docker 镜像

使用 GitHub Container Registry 上的预构建镜像，约 30 秒完成部署：

docker run -d --name deeptutor \
  -p 8001:8001 -p 3782:3782 \
  --env-file .env \
  -v $(pwd)/data:/app/data \
  ghcr.io/hkuds/deeptutor:latest### 🏠 本地优先 LLM 配置

简化后的设置页面现在仅聚焦于**本地 LLM 提供商**：

- ✅ **Ollama**（默认）
- ✅ **LM Studio**
- ❌ 移除云提供商（OpenAI、Gemini、Azure 等）

这符合 DeepTutor 隐私优先、自托管 AI 辅导的愿景。

## 📦 变更内容

### 核心基础设施

- 新增 `deeptutor/core/prompt_manager.py`，包含单例 `PromptManager`
- 从 `deeptutor/core/__init__.py` 导出 `get_prompt_manager()`
- 新增 `/api/v1/config/agents` 端点，用于数据驱动的前端配置

### 已迁移的 Agent 模块（10 个文件）

- `research/agents/base_agent.py`
- `solve/base_agent.py`
- `guide/agents/base_guide_agent.py`
- `question/agents/generation_agent.py`
- `question/agents/validation_agent.py`
- `question/validation_workflow.py`
- `ideagen/idea_generation_workflow.py`
- `ideagen/material_organizer_agent.py`
- `co_writer/edit_agent.py`
- `co_writer/narrator_agent.py`

### 移除遗留代码

- 删除 `deeptutor/agents/solve/utils/prompt_loader.py`
- 从 `BaseAgent` 移除 `use_prompt_loader` 参数
- 清理所有模块中的 `_PROMPT_CACHE` 类级缓存
- 从 `solve/__init__.py` 移除 `PromptLoader` 导出
