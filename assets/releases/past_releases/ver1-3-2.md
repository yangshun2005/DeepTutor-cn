# DeepTutor v1.3.2 发布说明

**发布日期：** 2026.04.29

v1.3.2 是 v1.3.1 之后的稳定性修复版本。本版收紧了嵌入端点约定，使 LlamaIndex RAG 能更干净地从过期或无效索引中恢复，并防止推理模型的草稿输出泄漏到长期记忆中。

## 亮点

### 透明的嵌入端点 URL

嵌入配置现在明确显示 DeepTutor 将调用的确切 URL。这消除了"基础 URL 与端点 URL"之间的隐藏歧义——该歧义曾导致设置页测试成功，但知识库重建索引时行为不同。

- **设置页现在为嵌入显示端点 URL** - Web 设置页将嵌入 URL 标注为端点 URL，并说明 DeepTutor 会原样向可见 URL 发送 POST 请求，请求时不会追加 `/embeddings` 或 `/api/embed`。
- **提供商默认值为完整端点** - OpenAI、OpenRouter、Jina、vLLM/LM Studio 和 SiliconFlow 默认使用 `/embeddings`；Ollama 默认使用 `/api/embed`；Cohere 默认使用 `/embed`；DashScope 保留其原生多模态嵌入端点。
- **旧版基础 URL 会安全迁移** - 使用旧式基础地址（如 `https://api.openai.com/v1`、`https://openrouter.ai/api/v1` 或 `http://localhost:11434`）的已保存嵌入配置会被规范化为完整端点形式，并写回模型目录。自定义 OpenAI 兼容 URL 保持不变。
- **配置错误的端点会尽早失败** - 嵌入客户端现在会拒绝已知提供商指向根路径/基础路径而非真实嵌入端点的 URL，并在索引开始前给出可操作的提示信息。
- **OpenRouter 嵌入使用精确 URL HTTP** - 公共嵌入提供商不再经过 OpenAI SDK 隐藏的路径追加行为。`custom_openai_sdk` 仍可用于旧版配置，但已从设置页的提供商下拉菜单中隐藏。
- **连接测试诊断与运行时行为一致** - 嵌入测试现在报告"按设置页所示原样 POST"，与 RAG 索引和检索使用的适配器行为一致。

### RAG 重建索引与检索韧性

LlamaIndex 流水线现在会更积极地刷新嵌入状态，并将无效的持久化向量转化为清晰的重建索引指引，而非原始的 Python 或 NumPy 错误。

- **缓存的流水线会拾取设置变更** - 初始化、搜索和增量添加路径在使用前会重新配置 LlamaIndex，因此长期存活的流水线不会保留旧设置会话中的嵌入模型、维度或端点设置。
- **配置变更时嵌入客户端会刷新** - 解析后的运行时配置发生变化时，共享嵌入客户端会被重建；LlamaIndex 的 `CustomEmbedding` 适配器在复用缓存客户端前会先对当前配置做指纹校验。
- **持久化索引向量在检索前会校验** - LlamaIndex 存储现在会在运行相似度搜索前检查已保存的向量存储是否存在空值、非数值、非有限值、缺失或不一致的向量。
- **无效索引返回重建索引提示** - 已知故障（如 `unsupported operand type(s) for *: 'NoneType' and 'float'`、向量形状不匹配以及新检测到的无效持久化向量）现在会返回 `needs_reindex: true` 并附面向用户的说明。
- **嵌入连通性检查使用同一校验路径** - 索引前的冒烟测试使用与索引和检索期间相同的批量校验器来验证提供商输出。
- **已知修复方案时 RAG 错误日志更安静** - 已分类的无效嵌入/索引故障会记录为可操作的警告，而非嘈杂的完整堆栈跟踪。

### 思考模型的内存清理

内存刷新现在会在私有推理块成为持久用户记忆之前将其剥离。

- **写入前移除思考标签** - 档案和摘要重写在代码围栏清理后经过共享的 `clean_thinking_tags()` 辅助函数，因此推理模型的 `<think>` / `<thinking>` 块不会被保存到 `PROFILE.md` 或 `SUMMARY.md`。
- **现有内存文件在读取时自修复** - 如果旧内存文件已包含闭合或未闭合的思考标签，读取快照时会清理内容，并在可能时把修复后的版本写回磁盘。
- **手动内存编辑使用相同清理** - 直接内存写入也会经过清理器，使 UI 编辑、刷新和运行时读取保持一致。

### 设置与运行时打磨

- **嵌入提供商选项不再令人困惑** - 设置页不再在公开下拉菜单中提供旧版 `custom_openai_sdk` 提供商，而已保存的配置仍可解析以保持向后兼容。
- **模型目录规范化会持久化** - 目录加载时，若规范化改变了活动配置/模型 ID 或嵌入端点 URL，现在会保存，防止同一迁移在每次启动时重复执行。
- **OpenAI 兼容嵌入错误更清晰** - 非 JSON 或 HTML 嵌入响应现在会指向端点/模型配对错误，而不会错误地暗示只有某一种网关特定原因。
- **Deep Solve ReAct 调用重新对齐** - 求解器循环不再向 `SolverAgent.process()` 传入过期的 `attachments` 关键字参数，避免了运行时 `TypeError`，同时在规划器和重新规划调用中保留了对附件转发的支持。

## 测试

- 新增 OpenAI、OpenRouter、Ollama 和自定义嵌入配置的端点迁移覆盖。
- 新增设置 API 对完整端点提供商选项和隐藏 `custom_openai_sdk` 的覆盖。
- 新增嵌入客户端对端点校验、OpenRouter 原始 HTTP 适配器路径、配置变更时客户端刷新以及精确 URL 透明性的覆盖。
- 新增 LlamaIndex 对过期嵌入客户端刷新、重复设置重配置、无效持久化向量检测以及无效索引重建索引提示的覆盖。
- 新增内存对闭合和未闭合思考标签的覆盖，以及读取期间对现有内存文件的修复。
- 运行了针对性的 Deep Solve/RAG 能力测试，覆盖修复过期 `attachments` 参数后的求解器运行时接线。

## 升级说明

- 设置页中的嵌入 URL 现在应为完整端点 URL。现有的已知提供商配置会自动迁移，但使用非标准路径的自定义网关应手动检查。
- 如果知识库搜索仍报告无效嵌入向量，请在确认活动嵌入提供商、模型、维度和端点 URL 后，对受影响的知识库重建索引。
- 包含旧 `<think>` 块的内存文件将在下次内存页或内存服务读取时被清理；该读取可能会更新底层 `PROFILE.md` 或 `SUMMARY.md` 文件以持久化清理后的版本。
