# DeepTutor v1.3.10 发布说明

**发布日期：** 2026.05.10

v1.3.10 是针对 v1.3.9 之后反馈问题的可靠性修复版本。恢复了更顺畅的远程 Docker 访问，使自签名 LLM 端点在各 SDK 支持的提供商间行为一致，保护代码片段不被引用重写，并将 Matrix E2EE 拆分为显式可选依赖。

## 亮点

### 远程 Docker 与 CORS 恢复

- **远程单用户 Docker 开箱即用** - 当 `AUTH_ENABLED=false` 时，DeepTutor 现在接受 HTTP/HTTPS 浏览器来源，局域网或远程服务器前端不再遇到 #463 中报告的 v1.3.8/v1.3.9 CORS 回归问题。
- **认证部署保持显式配置** - 当 `AUTH_ENABLED=true` 时，CORS 仍要求通过 `CORS_ORIGIN` 或 `CORS_ORIGINS` 提供明确的允许列表，保留凭据认证的安全边界。
- **支持多个部署来源** - `CORS_ORIGINS` 接受逗号或换行分隔的值，两个 Docker Compose 文件都会将该设置传递给后端容器。
- **设置不再丢失网络标志** - `CORS_ORIGIN`、`CORS_ORIGINS` 和 `DISABLE_SSL_VERIFY` 已纳入标准 `.env` 写入顺序。

### 提供商 TLS 与渲染修复

- **`DISABLE_SSL_VERIFY` 现已覆盖 OpenAI SDK 路径** - OpenAI 兼容、Azure OpenAI、executor、TutorBot 及旧版 embedding SDK 客户端在启用该标志时均使用共享的 `httpx.AsyncClient(verify=False)`，修复了 #464 中报告的自签名 HTTPS LLM 端点问题。
- **生产环境仍阻止不安全的 TLS 绕过** - `ENVIRONMENT=prod` 或 `ENVIRONMENT=production` 会拒绝 `DISABLE_SSL_VERIFY`，非生产环境使用时仅记录一条警告。
- **代码块保持数组索引完整** - Markdown 引用链接化现在会在重写引用前屏蔽围栏代码和行内代码，因此 `values[0]` 保持为代码，不会变成 `#references` 引用链接（#468）。

### Matrix 安装兼容性

- **Matrix 不再默认安装 E2EE** - 标准 `matrix` extra 和 `requirements/matrix.txt` 现在使用纯 `matrix-nio`，避免 macOS Python 3.14 和 Apple Clang 21 上出现的 `python-olm` / `libolm` 构建失败（#462）。
- **加密房间为显式附加项** - 需要 E2EE 支持且 libolm 可用时，安装 `deeptutor[matrix-e2e]` 或 `requirements/matrix-e2e.txt`。
- **运行时失败信息更清晰** - Matrix 默认使用非 E2EE 模式，在无加密依赖时启用 E2EE 会抛出可操作的安装提示，而非在导入时失败。

### 多用户运行时兼容性

- **默认工作区路径在用户范围外保持稳定** - 无当前多用户上下文时，路径解析回退到默认数据工作区，而非强制使用管理员范围。
- **旧版测试与 monkeypatch 钩子保持可用** - 会话和设置路由保留测试及旧版集成使用的兼容垫片。
- **本地 agent 产物被忽略** - `.claude/` 现已从 Git 中排除，本地工作树和 agent 元数据不会意外进入发布版本。

## 测试

- 新增 CORS 设置测试，覆盖未认证远程来源和认证显式允许列表。
- 新增共享 OpenAI SDK HTTP 客户端测试，覆盖 provider-core、Azure、executors、TutorBot 和 embedding 适配器。
- 新增 Markdown 显示测试，覆盖正文引用、围栏代码、行内代码和显式反引号引用。
- 新增 Matrix 依赖拆分测试，确保默认安装不含 `matrix-nio[e2e]`。
- 重新运行了针对性的 Python 测试、Web node 测试、Ruff 检查和发布补丁的 diff 空白验证。

## 升级说明

- 若以 `AUTH_ENABLED=false` 运行远程 Docker，正常 HTTP/HTTPS 浏览器来源无需额外 CORS 设置。
- 若以 `AUTH_ENABLED=true` 运行共享或认证部署，请将 `CORS_ORIGIN` 或 `CORS_ORIGINS` 设置为确切的前端来源，例如 `https://learn.example.com`。
- 仅在本地、自签名或隔离网络的测试 LLM 端点使用 `DISABLE_SSL_VERIFY=true`。在 `ENVIRONMENT=prod` 和 `ENVIRONMENT=production` 下仍会被阻止。
- Matrix 安装现在默认非 E2EE。如需加密 Matrix 房间，请安装 `.[matrix-e2e]` 或 `requirements/matrix-e2e.txt`，确保 libolm 存在，并在 Matrix 频道配置中设置 `e2ee_enabled=true`。
- 若此前仅为获取非加密 Matrix 消息而安装 `.[matrix]`，本次发布后重新安装应不再需要原生 libolm 构建工具。
