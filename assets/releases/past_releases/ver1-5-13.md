# DeepTutor v1.5.13 发布说明

**发布日期：** 2026.08.17

[v1.5.12](ver1-5-12.md) 讲的是答案素材从哪来。这一版主要讲 Book——把素材变成可*阅读*内容、而非聊天对象的界面。此前书能生成却没法真正使用：写入时页面卡死，声称跟踪的进度从未落盘，产出也带不出应用。这一版大部分工作就是补上这个缺口。首页也不再要求你从空白输入框开始。直接升级——无需迁移，无需重建索引。

## 新功能

### 观看书稿生成，完成后带走

编译的生命周期长于发起它的请求：`confirm_spine` 在页面骨架存在后即返回，而它排入队列的工作要跑几分钟。事件总线归该请求所有并随其关闭，导致后续事件全被丢弃，“观看书稿生成”退化成卡死的页面。现在事件流按*书*由进程持有，因此能挺过请求结束、刷新和重连。

阅读进度现在真正被记录。`visited_page_ids` 和 `bookmarked_page_ids` 自功能上线起只声明、从未写入；现在已访问页面、书签和测验作答会汇总为完成度评分和薄弱章节列表。

书也能带出应用：**导出为自包含的 Markdown 文档**。每种块类型都有文本投影，本质可视的块（渲染动画、交互组件）降级为描述加指引，而不是静默消失。非 ASCII 标题也能正常下载——此前中文或带重音的书名会直接导致请求失败。

### 批准前先知道书稿成本——且不重复付费

确认 spine 会触发数十次 LLM 调用和数分钟工作。编辑器现在显示基于 Section Architect 自身模板的逐章实时估算，因此数字不会偏离实际生成内容，且在你增删或改章节类型时保持准确。

修复了两个生产环境中不可见的调度缺陷：同一页面可能被并发编译两次——计费两次、一个结果被静默丢弃；书稿会在提供商故障期间硬撑到每章都半生成。源扫描也加了上限。此前无限制时，八个知识库对十几个查询会触发约一百个并发提供商调用；现在上限按轮询分配，不会全花在前几个库上。

### 已连接知识库不再静默零贡献

已连接 KB——Obsidian 库、远程 LightRAG 或 IMA 库、子代理 CLI——没有本地索引，因此 `rag_search` 对其返回空。书稿生成仍会扫描它们，而空结果与“无相关内容”的源无法区分：接上你的库，却从没人告诉你它贡献为零。检索现在区分已索引库和已连接指针，并分别路由。

### 三个起点，取自你实际在做的事

首页输入框现在提供三条起始建议，由你的记忆生成——L3 综合加上你近期跨界面的若干活动。它们提议一个具体要理解的东西，而非回顾历史的方式，并按语言控制长度以免溢出。新增的 `recall` 记忆读取为其提供支撑，快照时间戳读取时不加载实体内容。

### 掌握路径跟随对话

路径的生命周期长于任何单次聊天，一次聊天可能依次处理多条路径。在路径间移动进行中的回合现在集中在一处完成——租约、会话偏好和进行中回合一起变更，先释放后获取——因此被拒绝的交接会让学习者留在原处，而不是半移动。路径状态和回合恢复已加固，教学内容保持可见，定性复习已排期，删除会话会清理其路径。

### 腾讯 IMA 凭据上移到账户级

IMA 凭据过去只存在于每个 KB 上。现在也可在账户级从 **Knowledge → IMA 引擎页**解析，方式与 PageIndex 的密钥相同，当每 KB 的凭据对完整时仍优先。现有绑定不受影响继续工作，轮换账户密钥会更新所有依赖它的 KB。只读 IMA 连接和源文本检索一并修复。

### 其他

- **EPUB 成为受支持的知识库格式**，且 **Docling 可远程解析**，对接 Docling Serve 服务器（`mode=remote`），无需本地安装或下载模型。
- **生成的代码在送达你之前先解析。** 此前截断的片段会原样发出，没有任何未校验标记。
- **Overview 章节保持唯一。** 每次重新确认 spine 都会多出一个，且页面被整体重建——这是绕过 `edited_by_user` 保护的唯一路径。其措辞也不再硬编码为中英双语，而选择器提供十一种语言。
- **测验块直接读取问题流水线**，不再经过会丢弃最慢块进度的旧门面。
- **知识库：** 大文件上传经 Web 层流式处理，文档解析移出事件循环，docstore 探测在 `kb list` 中缓存并去重，GraphRAG 模型/嵌入兼容性已加固。
- **伙伴：** 数据按用户隔离，无效渠道配置不再拖垮其他渠道，工具列表跟随全局聊天开关，伙伴在标签页失活后会重连。
- **模型与提供商：** 模型目录和提供商传输会恢复而非持续损坏，目录密钥在设置 API 中受保护，GPT-5 代理工具使用 Responses API，提供商流失败边界可存活，完成的回合消息 ID 跨重连持久化。
- **运行时：** 活动 virtualenv 在 bwrap 沙箱内可见，无效 home 和占位 OpenAI 密钥被拒绝，Windows `.cmd` shim 在启动 CLI 前解析，控制台异常 traceback 保留，`mcp` 默认安装以便 PageIndex MCP 服务器连接。

## 升级说明

`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无 Schema 变更，无需重建索引，无需迁移。

- **本版之前编译的书没有记录的进度。** 完成度评分和薄弱章节从你下次阅读开始累积；不回填，也不重写任何现有页面。
- **升级时正在编译的书应恢复，而非搁置。** 事件流现在按书持有，重新打开会重新接入进行中的编译，而不是显示卡死页面。
- **`settings/ima.json` 是新增的可选文件。** 现有每 KB 的 IMA 凭据照旧工作——账户级凭据对只为不自带凭据的 KB 补位。
