# DeepTutor v1.5.5 发布说明

**发布日期：** 2026.07.26

这是 [v1.5.4](ver1-5-4.md) 的后续版本，新增两种接入模型的方式——使用自己的 ChatGPT 套餐登录，或通过 Eden AI 网关路由——知识库终于能说明自己实际包含哪些内容，GraphRAG 索引也不再需要循环变通方案。可直接升级，无需迁移；如果你运行过 v1.5.4，下面的聊天分支修复值得采纳。

## 新增内容

### 使用 ChatGPT 套餐登录（实验性）

**OpenAI Codex** 现已成为第一方 OAuth 提供商（[#690](https://github.com/HKUDS/DeepTutor/issues/690)）。在 **设置 → 模型 → LLM** 下选择它，浏览器登录会取代 API 密钥字段，模型列表从该账户的实时目录读取；在远程机器上则改为运行 `deeptutor provider login openai-codex`。凭据保存在 `<user-root>/private/openai-codex/`，仅所有者有权限，且绝不会读取或修改 `~/.codex`。由于令牌授权的是某个人的套餐，该配置按账户隔离：无法通过用户授权分配，且只有在尚未配置任何 LLM 时登录才会成为活动模型——它绝不会在你不知情的情况下改变部署所用的模型。此兼容路径为实验性；上游接口可能变化。

### Eden AI

[Eden AI](https://api.edenai.run/v3) 作为第 35 个 LLM 绑定加入（[#671](https://github.com/HKUDS/DeepTutor/issues/671)）——一个 OpenAI 兼容网关，用一个密钥即可访问众多提供商，模型以 `<provider>/<model>` 形式寻址。

### 知道自己包含什么的知识库

询问某个知识库有多少文件，或某文档是否在其中，答案不再来自查询恰好匹配到的那些分块。每个挂载的知识库现在都会在对话轮次中携带真实的文档清单，并新增 `kb_files` 工具，可按需枚举并支持 glob 和子串过滤——只要挂载了知识库就会启用，也可像其他工具一样按伙伴禁用。链接文件夹和 Obsidian 库就地枚举；远程 LightRAG 服务器会声明自己不可列举，而不是报告为零。知识库页面和聊天回答现在读取同一定义，因此不会再对同一个库给出不一致的说法。

### 可追溯的 RAG 引用

`rag` 工具过去只报告一个"来源"，而那不过是它自己查询的回声，使有依据的回答没有出处。现在它会转发检索实际返回的分块、实体和报告（[#694](https://github.com/HKUDS/DeepTutor/issues/694)）。本地 LightRAG 流水线只保留其合成答案，因此该引擎仍然没有可引用的内容。

### 无需循环变通方案的 GraphRAG 索引

GraphRAG 导入了一个拒绝 `uvloop` 的补丁——而 `uvicorn[standard]` 在 macOS 和 Linux 上给后端提供的正是该循环——因此除非为整个应用强制设置 `UVICORN_LOOP=asyncio`，索引会在导入时失败。现在每个 GraphRAG 入口点都在工作线程上运行，并使用自己独立的原生 asyncio 循环（[#695](https://github.com/HKUDS/DeepTutor/issues/695)），同时修复了两个导致首次索引运行失败的配置错误——文件模式中未转义的 `$` 和未注册的缓存类型（[#699](https://github.com/HKUDS/DeepTutor/issues/699)）。

### 其他修复

- 乐观消息 ID 重新保持唯一（[#698](https://github.com/HKUDS/DeepTutor/issues/698)）：用户行和助手占位符可能在同一毫秒内生成，合并为同一个持久化 ID，导致回复从可见会话中消失，直到重新加载。此问题由 v1.5.4 的就地轮次协调暴露。
- 在伙伴聊天中向上滚动会停留在你放置的位置，而不会被拉回底部（[#704](https://github.com/HKUDS/DeepTutor/issues/704)）。
- `claude-opus-5` 被识别为基于 effort 的模型，因此请求不再携带它拒绝的 `temperature`（[#703](https://github.com/HKUDS/DeepTutor/issues/703)）；Kimi 品牌的 Moonshot 模型现在完全省略该参数，而不是将其固定为 `1.0`。
- `deeptutor start` 在旧版 Windows 代码页上继续转发日志（[#702](https://github.com/HKUDS/DeepTutor/issues/702)）——Next.js 横幅中的一个 `✓` 过去会在 cp950/cp936/cp932 上杀死转发线程，使会话静默。

## 升级说明

从 v1.5.4 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移，无 Schema 或配置变更。

- 如果你曾为绕过 GraphRAG 索引问题而设置 `UVICORN_LOOP=asyncio`，现在可以去掉。
- OpenAI Codex 登录按设计为按账户隔离——每个用户自行登录，配置无法通过授权分发。
