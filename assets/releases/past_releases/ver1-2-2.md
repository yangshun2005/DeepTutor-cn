# DeepTutor v1.2.2 发布说明

**发布日期：** 2026.04.22

## 亮点

### 用户自编技能系统
引入完整的 **Skills** 子系统，用户可在 Web UI 中创建、编辑并激活自定义 `SKILL.md` 文件。每个技能位于 `data/user/workspace/skills/<name>/SKILL.md`，包含 YAML frontmatter（`name`、`description`、可选 `triggers`）和 Markdown 正文；激活后正文会原样注入聊天系统提示词。

- **后端** — `SkillService`（`deeptutor/services/skill/service.py`）提供 CRUD、列表和选择功能，带严格名称校验（`^[a-z0-9][a-z0-9-]{0,63}$`）、frontmatter 解析和目录级隔离。REST API 挂载于 `/api/v1/skills`，含 `GET /list`、`GET /{name}`、`POST /create`、`PUT /{name}`、`DELETE /{name}`。
- **前端** — 知识管理页（`web/app/(utility)/knowledge/page.tsx`）新增 **Skills** 标签页，内置 SKILL.md 编辑器；聊天输入框新增技能选择菜单。技能可单独切换，也可设为 **auto** 模式（向后端发送 `["auto"]`）。`web/lib/skills-api.ts` 提供带缓存的客户端 API 层。`UnifiedChatContext` 通过 WebSocket 载荷传递 `skills`。

### 聊天输入性能重构（#351、#360、#362）
通过深度状态共置消除长对话中的输入延迟：

- **`ComposerInput`** — 从 `ChatComposer` 中拆出为独立的 `memo` 组件，将高频按键重渲染与输入框其余部分（能力面板、引用标签、工具菜单）隔离。暴露命令式 `ComposerInputHandle`（`clear()`、`getValue()`），避免提升输入状态。
- **`SimpleComposerInput`** — TutorBot 聊天页的轻量变体，完全移除 @-mention 和能力相关开销，修复初次重构后残留的延迟。
- **配置面板加 `React.memo`** — `QuizConfigPanel`、`MathAnimatorConfigPanel`、`ResearchConfigPanel`、`VisualizeConfigPanel` 均包裹 `React.memo`；`ChatPage` 中的父级回调用 `useCallback` 稳定。
- **导出 @-mention 辅助函数** — `shouldOpenAtPopup` 和 `stripTrailingAtMention` 移至 `ComposerInput.tsx` 作为具名导出，供跨组件复用。

### `response_format` 被拒时的自动回退
在 v1.2.1 静态 `supports_response_format` 守卫基础上增加**运行时自动恢复**路径。当提供商对 `response_format={"type":"json_object"}` 意外返回 HTTP 400（常见于 LM Studio + Gemma/Qwen 类模型），两条 LLM 执行路径都会检测错误、去掉该字段并重试一次：

- **aiohttp 路径**（`cloud_provider.py`）— `_looks_like_unsupported_response_format` 启发式在 `_openai_complete` 和 `_openai_stream` 中检测拒绝；命中后去掉 `response_format` 重试，并缓存该（绑定、模型）组合。
- **OpenAI SDK 路径**（`executors.py`）— `_create_with_format_fallback` 包装 `client.chat.completions.create`，捕获 `BadRequestError` 并应用相同的重试 + 缓存逻辑。
- **运行时缓存**（`capabilities.py`）— `disable_response_format_at_runtime` / `is_response_format_disabled_at_runtime` 将发现的不兼容记录在模块级 `set` 中，后续调用直接跳过 `response_format`，无需付出重试成本。
- **`_answer_now.py`** — `stream_synthesis` 现在附加 `response_format` 前先检查 `supports_response_format`，从源头避免快速回答流程中的 400。

### 局域网 / 远程访问修复（#340）
局域网内其他机器打开 Web UI 时，构建期的 `NEXT_PUBLIC_API_BASE`（通常为 `http://localhost:8001`）会解析到远程浏览器自身的回环地址而非服务器。`web/lib/api.ts` 新增 `resolveBase()` 辅助函数，运行时检测该不匹配并将主机名替换为 `window.location.hostname`，使 `apiUrl()` 和 `wsUrl()` 无论从哪台机器打开页面都能访问正确后端。

### 侧边栏版本徽章与 GitHub 链接
侧边栏现在显示当前构建版本及状态指示：

- **`/api/version` 路由** — Next.js ISR 端点，查询 `api.github.com/repos/HKUDS/DeepTutor/releases/latest`（每小时重新验证，可选 `GITHUB_TOKEN` 缓解限流），返回最新标签、名称、URL 和发布日期。
- **`VersionBadge`** — 将 `NEXT_PUBLIC_APP_VERSION`（构建时经 `next.config.js` / `git describe --tags` 注入）与获取到的最新发布版本比较。最新时显示绿点，过期时显示琥珀色，未知时中性。点击跳转至发布页面。
- **`Dockerfile`** — 新增 `APP_VERSION` 构建参数传入 Next.js 环境变量，使基于 Docker 的部署也能准确显示版本。
- **GitHub 图标** — 折叠和展开两种侧边栏状态均添加仓库直链。

### Deep Solve 图片附件支持
`DeepSolveCapability` 现通过新增的 `_first_image_url` 辅助函数从 `context.attachments` 提取首个图片附件（data-URI 或 URL），并传给规划器和求解器 Agent。内部 `PlannerAgent` 和 `SolverAgent` 已重构为通过 `BaseAgent` 统一多模态流水线使用 `Attachment` 数据类，不再手动构造多模态消息数组——删除了两个重复的 `_build_multimodal_messages` 辅助函数。`BaseAgent.stream_llm` 也新增逻辑：当提供 `attachments` 但未显式提供 `messages` 时，从 `system_prompt` + `user_prompt` 构造消息；非视觉模型剥离图片时记录日志。

### Agentic Chat 流水线附件透传
`AgenticChatPipeline` 中的 `_stage_responding` 和 `_stage_acting` 方法现在构建消息后调用 `_prepare_messages_with_attachments`，确保用户上传的图片在每个聊天阶段都转发给 LLM——不再仅限于初始思考阶段。

### TutorBot WebSocket 韧性（#354）
加固 `/api/v1/tutorbot/{bot_id}/ws` 端点：

- **自动启动** — WebSocket 连接时若 bot 已配置但未运行，端点现在自动调用 `mgr.start_bot()`，而非立即以 4004 关闭。未知 bot ID 仍在关闭前返回 JSON 错误载荷。
- **`_safe_send` 包装** — 所有 `ws.send_json` 调用经过辅助函数，捕获 `WebSocketDisconnect` / `RuntimeError`，防止客户端中途断开时出现未处理异常。
- **优雅断开** — `_handle_user_messages` 在 `receive_text` 上捕获 `WebSocketDisconnect` 并干净退出。

### 设置页：API Key 掩码（#355）
设置页的 API Key 字段默认渲染为 `type="password"`，带 Eye / EyeOff 切换按钮。切换服务或配置时可见性状态重置。

### 书库 UI 重构
将极简的"选择一本书"占位符替换为完整的 **BookLibrary** 组件（`web/app/(workspace)/book/components/BookLibrary.tsx`），含搜索、按状态过滤的卡片（显示章节/页数）、创建和删除操作、状态徽章（草稿 / 大纲 / 编译中 / 就绪）。`BookSidebar` 简化为单书阅读视图，带"← 所有书籍"返回按钮；书籍页根据当前视图条件显示书库或侧边栏。

### 可视化全屏模式
SVG、Mermaid 和 ChartJS 可视化新增 **最大化** 按钮（右上角），在带 Escape 关闭的全屏覆盖层中打开图形。HTML iframe 可视化除外，因其已自带"在新标签页打开"功能。

### Bug 修复
- **嵌入适配器 `ConnectError` 未重试（#353）** — `OpenAICompatibleEmbeddingAdapter` 的重试异常元组加入 `httpx.ConnectError`，嵌入期间的瞬时连接失败将以指数退避重试，而非立即抛出。
- **RAG `None` 嵌入加固** — `CustomEmbedding._aget_query_embedding` 和 `_aget_text_embedding` 在提供商返回 `None` 时抛出明确的 `ValueError`，而非在后续相似度计算中崩溃。批量方法 `_aget_text_embeddings` 现在从同级向量或配置的 `dim` 确定回退零向量维度，两者均不可用时抛出异常（防止零长度向量被静默持久化）。
- **KB 删除时目录缺失崩溃** — `KnowledgeBaseManager.delete_knowledge_base` 现在直接通过 `self.base_dir / name` 解析路径，并处理磁盘文件夹已被移除的情况，清理孤立的 `kb_config.json` 条目，而非抛出 `FileNotFoundError`。
- **CLI `parse_json_object` 空白字符** — 函数现在解析前去除首尾空白，shell 管道产生的尾部换行不再导致 `json.JSONDecodeError`。
