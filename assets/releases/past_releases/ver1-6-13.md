# DeepTutor v1.6.13 发布说明

**发布日期：** 2026.10.04

在 [v1.6.12](ver1-6-12.md) 基础上，v1.6.13 扩展了阅读、听力和题库练习，改进了文档解析和语音配置，新增波兰语及更多模型提供商。聊天附件现在跟随所选工作区，迁移期间已有上传文件和 URL 保持可用。

## 新增内容

### 阅读、聆听与回顾

沉浸式阅读新增自然朗读音频和测验星级奖励。沉浸式观看新增带时间戳的标记、笔记和建议复习点。PDF 缩放和 EPUB 章节导航能更可靠地保留阅读位置；学习者可在授权范围内打开明确分配的书籍和阅读材料。

### 从题库开始练习

可直接从题库开始练习，并选择多道已保存的题目发起聊天。引导式学习会打乱多选题选项顺序，避免通过选项字母或检索提示泄露正确答案。协同写作支持为编辑操作选择模型。

### 更可靠的文档检索

可为文档图像描述选择独立的视觉模型；成功的描述按工作区缓存，并可选启用有界批处理。MinerU 云端解析会切分超大 PDF 并续传已完成部分，本地失败会报告可操作的错误原因。可选的微小扫描归一化、编号习题查找和更好的图表保留提升了教材检索效果。`deeptutor kb eval` 可基于本地评估数据集衡量检索质量。

### 能解释失败原因的语音设置

语音模型新增可配置的合成超时，供预览和播放使用。DashScope Qwen-Audio 和 Qwen3 TTS 使用各自的端点、音色、格式和区域要求。预览错误可区分认证、权限、参数、配额、网络故障和超时。回复播放会保留数学内容、取消过期请求并防止音频重叠。

### 工作区与连接

新聊天上传的文件存放在所选工作区的 `chat/attachments` 目录，便于工作区工具找到它们。早期上传的文件会在其对话被使用或数据迁移时移入该目录；已有附件 URL 仍可读取。SearXNG 连接测试会说明 Docker 寻址、JSON 输出被禁用和搜索结果为空等问题。网页来源可配对双语内容，知识库检查复用探测而不阻塞 API。

### 伙伴、语言与提供商

可将伙伴群组对话导出为 Markdown，并按聊天配置 Telegram 响应策略。飞书投递和 Telegram 代码块更可靠。波兰语加入界面语言；Requesty、API Route 和 FutureInfra 加入 LLM 提供商，并原生支持 MiniMax 语音和小米 MiMo v2.5 预设语音。

### 聊天恢复与日常修复

历史搜索会检查完整对话记录并排除已回收的会话。长对话分支、重连提交、LaTeX 选区和学习者路由的恢复更可靠。图像载荷不再虚增 token 估算，GLM 推理选项与支持的设置一致，`deeptutor doctor` 遵循已配置的提供商和 token 预算。

随版本更新的安装和功能文档见 [deeptutor.info](https://deeptutor.info/)。

## 升级说明

运行 `pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。

- **附件：** 无需手动移动。早期上传的文件会在需要时迁入所选工作区；升级期间请保持现有应用数据挂载。
- **语音：** 合成需要更多时间时，在语音模型中设置 **请求超时（秒）**；默认 60 秒，支持范围 5–600 秒。使用 **预览音色** 测试合成；仅获取模型列表不能验证音色。
- **DashScope Qwen-Audio TTS：** 使用北京区域的 API 密钥和所选模型支持的音色。提供商 API 基础 URL 会自动选择匹配的语音端点；Qwen3 TTS 使用自己的音色和 WAV 输出。
- **文档图像：** 若主模型无法检查图像，请在文档解析设置中选择图像描述模型。批处理和微小扫描归一化是可选项；较早的已索引内容需重新解析和重建索引，才能获得新生成的描述或图表记录。
- **学习者书籍：** 管理员必须授予书籍界面并明确分配书籍；学习者访问范围仅限于这些分配。
- **systemd 安装：** 停止服务，在其 Python 环境中升级 DeepTutor，然后重启服务。
