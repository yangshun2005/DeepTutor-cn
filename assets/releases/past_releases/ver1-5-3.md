# DeepTutor v1.5.3 发布说明

**发布日期：** 2026.07.24

在 [v1.5.2](ver1-5-2.md) 基础上的维护版本：代码块主题可自定义，My Agents 新增四个编码 CLI，新增一个 LLM 提供商，并集中修复了聊天、记忆、嵌入和解析方面的可靠性问题。直接升级，无需迁移。

## 新增内容

### 可自定义主题的代码块

**设置 → 外观** 新增 **代码块** 面板：可选择语法高亮主题、切换行号、设置长行是否换行，并带实时预览。选择按账户保存，应用于聊天、Book 和 Co-Writer 中所有代码渲染处。

### My Agents 新增四个编码 CLI

除 Claude Code 和 Codex 外，现在可在任意聊天轮次中连接并咨询实时运行的 **Gemini CLI**、**Kimi CLI**、**opencode** 或 **MiMo Code**——每个都会在本机检测、可选择模型，并通过 `consult_subagent` 流式输出到 Activity 面板。

### 更广泛、更稳定的提供商支持

- **Atlas Cloud** 作为 LLM 提供商加入（`atlascloud`），绑定总数达到 34 个。
- DashScope 文本嵌入模型现在路由到正确的文本端点；对拒绝 `encoding_format` 的 OpenAI 兼容网关，默认省略该参数——修复了严格代理下的嵌入失败。

### 可靠性修复

- **聊天** — RAG 与独占知识能力共存，不再被抑制（[#650](https://github.com/HKUDS/DeepTutor/issues/650)）；可解析 DeepSeek 的 DSML 文本工具调用标记（[#666](https://github.com/HKUDS/DeepTutor/issues/666)）；手动向上滚动时自动滚动解除（[#649](https://github.com/HKUDS/DeepTutor/issues/649)）。
- **记忆** — `write_memory` 偏好添加具备幂等性（[#647](https://github.com/HKUDS/DeepTutor/issues/647)）；事实和行编辑 JSON 即使带尾部文字也能正确解析。
- **Personas** — 对等 / 教师 / 研究助手预设随版本预置（[#659](https://github.com/HKUDS/DeepTutor/issues/659)）。
- **Book、Partners、Visualize、CLI** — 长时间运行的 Book 操作通过 WebSocket 流式传输；partner 文件名去除控制字符，消息拆分不再挂起；Visualize 接受无空行结尾的代码围栏；CLI 加固 UTF-8 终端输入。

## 升级说明

从 v1.5.2 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。无需迁移——现有知识库、partners、personas 和掌握路径继续可用。一项打包变更：DeepTutor 现在要求 **Python 3.11–3.13**（`requires-python = ">=3.11,<3.14"`）；在 3.14 上，`pip` 找不到部分编译型基础依赖（如 `faiss-cpu`）的 wheel，现在会给出可读的报错信息，而不是源码构建失败（[#664](https://github.com/HKUDS/DeepTutor/issues/664)）。
