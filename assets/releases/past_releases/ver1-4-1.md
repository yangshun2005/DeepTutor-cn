# DeepTutor v1.4.1 发布说明

**发布日期：** 2026.05.27

v1.4.1 是 [v1.4.0](ver1-4-0.md) 的安全与稳定性补丁。它收紧了 TutorBot 工具沙箱，隔离了各用户资源，修复了 v1.4.0 的聊天回归问题，新增了与特定 TutorBot 对话的 HTTP API，并为 DeepTutor 没有视觉能力条目的提供商提供了多模态图像回退修复。

## 新增内容

### TutorBot 工具沙箱改为按需启用
除非管理员设置 `allow_shell_exec`，否则不再注册 shell `exec` 工具，且所有文件系统与 shell 访问默认限制在 bot 工作区内。命令拒绝列表重新锚定在命令边界上，且 `allow_shell_exec` 无法通过更新载荷开启。

### 按用户隔离资源
书籍根目录、会话数据库、轮次运行时存储和 TutorBot 目录均按用户划分，Web/API 会话按会话键控——跨用户请求无法访问彼此的数据。

### 面向 TutorBot 的 HTTP / SSE API
新增 `POST /{bot_id}/chat` 和 `/chat/execute-stream`（SSE）端点，支持自动启动和持久化的按会话上下文，供外部客户端与特定 bot 进行多轮对话。

### 多模态图像回退
图像会乐观地发送给每个提供商；如果携带图像的请求失败且模型不在已知视觉允许列表中，该轮次会以纯文本重试。修复了豆包 / 火山引擎及其他缺少能力条目的多模态模型上图像被静默丢弃的问题。

### 安全 ZIP 上传 + 网络设置
`.zip` 知识上传会通过文档校验器逐成员展开，并带有大小 / 数量 / 压缩比边界和路径逃逸防护；压缩包本身不会被索引。新增的 `/settings/network` 页面展示端口、公共 API 基址和 CORS 源（已规范化以兼容 `host:port` 和尾部斜杠），并提供"获取模型"操作，从 OpenAI 兼容端点列出模型 ID。

## 社区修复与变更

**安全** — 关闭了 TutorBot 通过 shell 工具的 RCE（#518）、文件系统工具中的路径遍历（#517）、跨 bot 文件管理的授权绕过（#516）、跨会话轮次重新生成的授权绕过（#515）、书籍确认的授权绕过（#514），以及 ExecTool 通过聊天执行 LLM shell 命令（#506，首次在 PR #507 中加固）。

**Bug 修复** — 首轮后聊天输入被禁用（v1.4.0 回归，#520）、长文档的知识库嵌入失败（#521 / PR #509）、Docker 下新用户无法创建配置文件（#512 / PR #513）、Qwen 推理模型原生工具调用失败（#527 / PR #528），以及 GPT-5 初始化向导的 token 参数（PR #508）。

**已合并 / 重做的 PR** — 推理模型的原生工具调用（#528）、超大会话事件截断（#524）、空状态配置文件按钮（#513）、分块流水线修复（#509）、GPT-5 探测（#508）、ExecTool 加固（#507）。贡献 #522（zip 上传）和 #523（模型获取 + notebook 查找）已在本地重新实现并随此版本发布。

**功能请求** — 与特定 TutorBot 多轮聊天的 HTTP API（#511）。

## 升级说明
- 可从 v1.4.0 直接升级：`pip install -U deeptutor`；Docker 用户拉取 `ghcr.io/hkuds/deeptutor:latest`。
- **TutorBot shell exec 现在默认禁用。** 如果你依赖它，请在 bot 上设置 `allow_shell_exec`；工具访问仍限制在工作区内。
- 跨站 HTTPS 认证需设置显式 CORS 源和 `cookie_secure=true`。
