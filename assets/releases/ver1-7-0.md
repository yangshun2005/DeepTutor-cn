# DeepTutor v1.7.0 发布说明

**发布日期：** 2026.10.28

在 [v1.6.15](past_releases/ver1-6-15.md) 基础上，v1.7.0 带来模块化安装、全新学习工作区、带 Dito 的块式笔记本，以及旁白视频课程。完整应用升级现使用 `deeptutor[full]`；现有运行时数据与已安装包保持分离。

## 新增内容

### 按需安装所用部分

`deeptutor` 现提供核心聊天、CLI 和 SDK；`deeptutor[full]` 选择 Web 应用和标准功能模块。`deeptutor-cli` 包成为兼容性别名。用 `deeptutor module list` 查看已安装、已启用和就绪状态，然后在应用停止时启用、禁用、安装或移除模块。依赖检查保护必需模块，移除时保留用户数据。

### 围绕学习组织的工作区

Modern 和 Classic 布局提供不同的导航排列。Home 汇集 Chat、Task Board、Learning 笔记本和 Calendar；Learning 和 Resources 保持学习活动与材料可访问。自定义 Chat 模式、控件和起始提示，或选择 New learning 页面显示哪些学习方法。对话和资源导航保留各自的工作区边界。

### 笔记本页面与 Dito 并排

Learning 笔记本以页面、子页面和块取代原 Co-Writer 编辑器。导入 Word 文档，从 Favorites 插入来源记录，与 Dito 讨论某段文字，并在接受前审阅建议的编辑。将页面导出为 Markdown 或 Word。Favorites 保存来源记录；笔记本页面保存你自己的写作和理解。

### 视频课程与免费朗读

选择 Video Lesson 生成直接在浏览器中播放的课程，带字幕和可选的 Microsoft Edge 旁白。帧检查在有界 WebAssembly 解释器内执行生成的代码；无需 Docker。Microsoft Edge 也加入朗读提供方，iOS 上的回复播放更可靠。

### 更可靠的辅导与索引

兼容的中断 LlamaIndex 重建可恢复已完成的嵌入检查点。知识库创建保留同名文档，一个失败的字幕组不再中止整个摄取。Chat 更一致地恢复 worker 故障，已完成的 Anthropic thinking 从历史重放中排除，提示缓存使用更稳定的对话前缀。Guided Learning 在检查引用时保留数学含义，并将审阅工作限制在资格门槛内。

英文和中文指南已随本版本在 [deeptutor.info](https://deeptutor.info/) 同步。

## 升级说明

- **完整应用：** 停止 DeepTutor 并备份运行时主目录，然后运行 `python -m pip install --upgrade "deeptutor[full]==1.7.0"`。使用相同的 `DEEPTUTOR_HOME` 重启前，运行 `python -m pip check` 和 `deeptutor module list`。裸 `deeptutor` 现仅选择核心。
- **旧版 CLI 包：** 先运行 `python -m pip uninstall deeptutor-cli`，再安装新的核心或完整配置。可选重装 `deeptutor-cli==1.7.0` 作为兼容性别名。旧 CLI 拥有共享 Python 文件，在同一事务中升级它可能移除新核心所需的文件。移除包不会影响运行时主目录数据。
- **源码安装：** 安装 `requirements/full.txt`，然后 `python -m pip install -e . --no-deps`。可选源码依赖使用 `python scripts/install_extras.py <extra>`。源码检出支持模块启用/禁用；包安装/卸载需要 wheel 环境。
- **Docker：** 拉取 `ghcr.io/hkuds/deeptutor:1.7.0` 或 `:latest`，并使用现有数据卷重建容器。
- **Video Lesson：** 后端需要 Node.js 22+ 和 npm；首次使用会下载固定版本的渲染包。安装 `edge-tts` extra 以启用旁白。无可用旁白时，课程保留字幕并静音播放。
- **模块版本：** 核心和功能 wheel 必须匹配。更改模块前停止活动服务器和 CLI 轮次；检查依赖阻塞项，而不是在运行中的应用下卸载包。参见[模块安装与迁移](../../docs-for-dev/MODULES.md)。
