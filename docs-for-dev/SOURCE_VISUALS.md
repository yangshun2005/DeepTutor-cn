# 知识库中的源图像

[手册](README.md) · [相关指南](INDEXING_RECOVERY.md)

当 PDF 或 EPUB 解析器输出图像文件时，DeepTutor 可以保留提取出的源图像。知识库以确定性资产 ID、文档哈希、解析器标识、源定位符、标题和邻近文本，存储经校验的解析器提取的 PNG、JPEG、GIF 或 WebP 字节。结构化解析器块在可用时还会保留页码索引和边界框。图像记录存放在知识库的 `visual_assets/` 目录下，与向量索引分离。经访问校验的 API 路由 `/api/knowledge-bases/{kb_name}/visual-assets/{asset_id}` 提供这些精确字节，删除原始源文件会移除其图像资产。

LlamaIndex 知识库流水线为每个源图像索引一条文本记录，因此文本嵌入模型可通过标题和上下文检索到它。当 `rag` 在聊天循环中检索到该记录时，具备视觉能力的回答模型会在下一次请求中收到经校验的图像像素。纯文本模型会收到标题和上下文，并附带明确警告：它未看到像素。所有受支持的提取图像都会保留，每张图像限制为 5 MiB，一次模型续写最多发送两张检索到的图像。文档保留数量与此模型请求预算无关。没有文档图像数量上限，也没有知识库级 16 MiB 清单上限。不可读的清单会显式导致写入失败并保持保留状态。

当前提取覆盖范围取决于所选解析器。MinerU 可输出结构化 PDF 图像。PyMuPDF4LLM 在启用图像提取时可输出 PDF 和 EPUB 图像，但其 Markdown 输出不提供页面框。默认纯文本解析器和当前 Docling 适配器不输出源图像资产。仅为矢量绘图命令的图像，或在未配置可用 OCR 引擎时需要 OCR 的页面，可能缺失。其他 RAG 提供方尚未为此图像清单建立索引以支持语义发现。精确图像和 PDF 页面检查与嵌入引擎无关。

## 精确图像、原始页面与覆盖范围

在知识库的文件视图中，选择文档并展开 **源图像覆盖范围**。它会显示保留的图像、分页的原始图像链接，以及已知的跳过、失败或未验证的提取位置。解析器未返回图像，绝不代表文档没有视觉信息。该报告描述提取情况；它不证明索引就绪，也不证明书中每张图像都已覆盖。

现有 `rag` 工具还接受 `source_path`、`figure`、`asset_id`、`page`、`region` 和 `source_hash`。使用 `kb_files` 获取精确文档路径。图像和表格引用保留其类型和编号；英文/中文标签等价。不同来源共享的标签存在歧义，需要选择。对于概念发现，使用现有语义检索，必要时用源语言查询。将得到的文档、章节、标题和页码放在一起，而不是把相似图像当作匹配。

对于矢量绘图、稀疏标题或依赖布局的表格，直接检查 PDF 页面。精确印刷引用发现仅扫描选定的未锁定 PDF，最多 2000 页；多次提及仍作为页面选项。已知页面可独立于该发现限制进行选择。渲染在本地读取原始 PDF，无需 OCR/模型下载或云调用。整页保留布局；归一化 `region=[x0,y0,x1,y1]` 裁剪将有限像素预算用于更多细节。同一 PDF 页面上解析器提供的面板组解析为完整页面。结构化表格表头/单元格/单位和注释在提供时仍作为文本证据；原始页面可用于验证。

页面检查支持最大 512 MiB 的 PDF，最多 800 万渲染像素和 5 MiB 图像字节。锁定/损坏的 PDF、无效区域和不可读标签有明确限制。其他格式保留受支持的提取图像和原始文档访问；PDF 渲染不会静默应用于它们。提高渲染比例不会恢复扫描件中缺失的信息。

每条解释都包含原始像素和源位置。标题和页面文本与观察到的图像事实相区分。详细追问时重新检索同一不可变 `asset_id`；`source_hash` 保护页面链接。兼容的重新索引会保留旧资产 ID 可用。已更改或缺失的源会被报告，旧引用绝不会重定向到新材料。在单独的有界调用中比较两个源。如果任一证据无法检查，选择页面/区域、澄清来源，或说明无法进行受支持的比较。无需整本书图像上传或强制外部增强。

合成回归夹具包含 100 张源图像，以及矢量、结构化表格和多面板页面。预期的早期/中期/晚期引用、中英文图像标签、表头/单位/注释、原始字节、歧义匹配、不可用像素和源更改弃权，均独立于语言模型流畅度进行检查。

## 基于源材料的练习与学习证据

在引导学习中，显式请求解释、练习或复习。仅解释的回合无需提问；`mastery_note_explained` 记录所教内容，但不授予掌握。推迟目标会将其保留为未完成。对于需要视觉理解的目标，大纲目标可声明 `required_visual_tasks`：`identification`、`relationship`、`table_graph` 或 `comparison`。通用文本分数无法满足这些视觉要求。目标视图显示剩余的独立证据。

从附加知识库中请求针对精确原始图像或页面的练习。导师检索其像素，然后提出带 `visual` 上下文的 `mastery_quiz`。问题卡显示原始证据和文档/页面链接。支持编号标签识别、有源支持的关系问题、表格或图表解读以及有界双源比较。不使用自动分割、虚构标签掩码或生成替代图。源图像加载失败会禁用提交，但仍允许学习者跳过或求助。

参考键使用规范源术语和支持性标题、解释或页面引用。显式验证的等价术语（包括其他语言）可回答同一问题。选择题区分有支持的错误答案；未知自由文本措辞会要求澄清，而不是模糊关键词评分。不确定/冲突的键、不可访问或已更改的源，以及缺失的模型输入像素保持未评分，且不产生负面掌握或保留证据。图像 URL 或声明的视觉能力不足：活动循环会检查已接受提供方请求中匹配的图像字节，包括实际的纯文本回退。

可见/未知答案线索属于引导练习，保留辅助并产生较弱复习证据。它们不证明独立掌握。暴露参考答案的完整页面保持引导性质；当答案线索在视图之外时，经校验的原始页面区域可支持独立解读，完整源保留用于参考验证。最近的辅助、重复暴露答案键以及提问后提供的帮助，也可通过现有保留会话边界加以区分。

使用 **复习或质疑此评估** 请求源审查。现有 `mastery_repair_question` 使错误评估失效，并重新计算其掌握/错误/复习影响。纠正视觉键也需要源支持；仅质疑绝不授予掌握。手动学习者覆盖保留其独立来源。源/图像身份、目标、任务、线索/帮助、答案和尝试身份在重启后保留。传输重试记录一次尝试；新问题记录新证据。大纲替换保留可信目标身份，而不是按标题或位置转移成就。未评估、已解释、已辅助和独立展示的工作保持区分。

回归工作流使用独立指定的合成编号图像、关系和表格值，包括等价语言答案、错误选项、未评分歧义、修复、推迟、重复提交、大纲替换、源更改和重启。此受支持集为不确定性提供显式恢复，而不是承诺对每张图像或任意散文答案进行无限制评分。

## 图像请求的 Token 估算

当提供方返回用量时，DeepTutor 使用这些报告的计数器。当用量缺失时，对话统计标记为估算。回退按约每 token 3.5 个字符计算序列化文本，并为每个结构化图像块增加 1,024 个 token。它从文本估算中排除图像 URL 和 Base64 载荷，因此编码文件大小不会将计数器膨胀到数百万 token。

图像配额是粗略占位符，与分辨率、细节、模型和提供方无关；它不是计费计算。回合中的每次模型调用仍计算其自身输入，包括任何重放的图像。现有存储的估算不会因此更改而重写，对话内容保留。

## 恢复 MinerU 云 PDF 切片

大型云 PDF 使用文档解析设置中的 `engines.mineru.max_pages_per_part` 切片（默认 180；限制在 1–200）。保存旧版 MinerU 设置表单时保留此高级设置。本地解析和小型/非 PDF 输入保持现有行为。

合并内容列表的 `page_idx` 值引用原始 PDF，包括嵌套块。例如，第二个 180 页切片的页码索引 0 变为 180。无效本地索引会使解析失败，而不是静默错误标记源页面。其他每部分诊断产物保留其原始本地编号和 `partNN_` 文件名前缀。

完成的切片归档保存在活动工作区解析缓存下的 `.mineru-segments/` 中，位于可丢弃的失败解析目录之外。重试相同源和解析器设置会复用完成的切片；更改的文档、端点、模型、语言、OCR/公式/表格设置或切片大小会启动新的检查点集。API token 和签名 URL 绝不写入检查点。每个归档在复用前进行 SHA-256 校验；不完整或损坏的检查点会重新下载。并发任务仍可能重复云请求，但检查点写入是原子的。缓存写入失败不会使成功的解析失败。

这些归档包含解析的文档内容、图像以及 MinerU 返回的任何源副本，就像正常解析缓存一样。它们保留到工作区缓存被清除；在没有解析运行时删除 `.mineru-segments/` 只会丢弃可恢复进度。此更改对云解析器签名进行版本化，因此较旧的合并页码索引不会从正常解析缓存中复用。现有知识库索引需要显式重建才能使用修正后的页面。

## 重试本地 MinerU 文档

本地 MinerU 重试从开头重新启动中断的文档；CLI 不会在推理调用内暴露可靠检查点。兼容的已完成文档解析在重试或重启后仍可复用，包括仅嵌入配置更改时。空或不可读的缓存输出会重新解析，而不是被接受为完成。

新本地输出在替换现有解析前会检查可用的 markdown 或内容块。失败的尝试保留其产物用于诊断。在工作区解析缓存中，这些产物被移动到受影响签名旁的隐藏 `.failed-` 目录，位于下一次重试的工作目录之外。它们绝不会被视为完成的缓存条目。清除工作区解析缓存也会移除这些诊断产物。中断的本地子进程在调用方开始另一次尝试前被停止。

## 使用 MinerU 处理微小扫描 PDF 页面

某些扫描 PDF 在异常小的物理页面框中编码全分辨率页面。MinerU 官方云后端可在临时上传副本中选择性放大这些页面。原始文件、页面顺序、压缩图像字节和软掩码保留；语言、OCR、模型、公式和表格设置保持配置不变。这是几何变通方法，不保证更好的 OCR 或保留任意交互式 PDF 语义。

该选项默认关闭。管理员可通过现有 `PUT /api/settings/document-parsing` 端点使用以下部分载荷启用：

```json
{"engines": {"mineru": {"normalize_tiny_scans": true}}}
```

使用 `false` 禁用。该选项也位于 `document_parsing.json` 中的 `engines.mineru.normalize_tiny_scans`。启用它会更改云解析缓存签名；旧解析保持完整。现有索引不会自动重建。可选 `deeptutor[parse-pymupdf4llm]` wheel 额外项提供所需的 PyMuPDF 依赖。对于源检出，使用 `python scripts/install_extras.py parse-pymupdf4llm`（参见[模块安装](MODULES.md#source-checkout)）。

仅最长边低于 144 点、高分辨率图像覆盖至少 80% 页面且表观密度至少 1200 DPI 的无文本页面符合条件。最长边缩放到 768 点。旋转、裁剪、注释、含矢量或非默认 UserUnit 的页面保持不变。本地 MinerU、自定义云端点、普通 PDF 和非 PDF 输入保持现有行为。临时副本在成功或失败后移除，如果压缩图像流发生变化则拒绝上传。

## 可选图像描述批次

现有 LlamaIndex 图像描述传递可在每个视觉请求中发送多张图像。通过 `PUT /api/knowledge-bases/rag-pipelines/llamaindex/config` 设置 `image_description_batch_size`，例如：

```json
{"image_description_batch_size": 4}
```

默认值为 `1`，保留单独请求；接受值限制在 1–8。启用时并发限制按批次计数，现有超时覆盖整个批次，包括任何拆分尝试。返回的标题通过显式 ID 匹配，绝不按响应顺序匹配。格式错误的 JSON/ID 映射和显式上下文溢出会拆分为更小的组，最终使用现有单图像提示。N 张图像的组最多进行 2N−1 次补全调用，此模式下禁用提供方重试。身份验证和速率限制会停止作业中排队的组；其他 API/传输错误不会拆分。

这仅影响现有 LlamaIndex 描述传递中后续处理的图像。它不会为结构化源图像启用描述，也不会更改阅读材料标题。批次使用不同的结构化提示，并将完整、成功的组与独立单图像标题分开缓存。摘要包括有序图像内容和元数据、提示、模型身份和重试策略。失败、不完整或取消的组不缓存；成功的拆分组可复用。将大小设回 `1` 恢复正常的单图像路径。模型必须支持多个图像块；不支持的 API 响应会被报告，而不会引发大量回退请求。
