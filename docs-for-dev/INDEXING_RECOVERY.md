# 长文档索引与恢复

[手册](README.md) · [相关指南](EVENTS_AND_PROGRESS.md)

每个知识库在 `.indexing-run.json` 中记录最近一次索引运行。文件/详情视图提供 **索引恢复详情**，包括各来源结果、当前阶段及阶段内计数、已用运行时长、距上次输出/活动的时间，以及距上次可衡量进展的时间。某阶段到达最后一批并不代表整个索引已就绪。中断后未知的工作仍是未知，绝不会被计为成功文档。

`GET /api/knowledge-bases/{id}/indexing-readiness` 执行轻量的解析器、格式和嵌入配置检查，不下载模型，也不向提供方发送请求。就绪检查不保证后续下载、可用内存或 GPU 显存，也不保证提供方的运行时响应。运行时失败会在持久化运行记录中保留其有界、已脱敏凭据的原因。

重试使用现有的内容寻址解析器缓存：源字节和解析器签名必须匹配，且可用文本或块必须仍然存在。MinerU 云端 PDF 切片仅复用已验证的检查点。更改嵌入可复用解析结果，但会为新嵌入签名构建独立的索引版本。没有可用检查点的中断阶段会重新开始；日志本身不是第二层缓存，也不会伪造部分嵌入。

取消是任务特定的，并在安全边界生效。受管本地 MinerU 进程也会响应取消，并在 600 秒无输出或总计 7200 秒后失败。其他同步引擎无法任意中断；取消会保持挂起，直到它们返回。停滞的 LlamaIndex 执行器在实际退出前，禁止与同进程重试重叠，且失去所有权后无法发布其候选版本。

LlamaIndex 重建和增量添加使用全新的版本目录。候选版本在持久化索引重新加载、向量验证通过，且使用已存储向量的检索探测返回节点之前，保持未发布状态。发布元数据以原子方式写入。索引期间的源变更会拒绝发布。失败或部分完成的候选版本不会覆盖之前可查询的版本。已完成和失败的来源会分别报告，包括部分成功。持久化日志的作用域为当前用户/工作区知识库；链接/只读知识库无法通过变更路由取消。
