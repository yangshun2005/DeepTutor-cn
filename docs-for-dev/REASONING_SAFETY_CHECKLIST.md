# 长程推理与安全核查清单

[手册](README.md) · [相关指南](AGENT_SETUP.md#6-troubleshooting)

当辅导回答看起来不可靠、中途改变假设、引用证据薄弱，或未能反映学习者所选材料时，使用本清单。本清单刻意用于诊断：帮助用户收集有用证据，帮助维护者区分提示词问题、检索问题、上下文问题或产品缺陷。

## 快速诊断问题

1. 学习者最初要求什么，哪些约束或定义仍然有效？
2. 运行了哪个能力，启用了哪些工具，实际发生了哪些工具调用？
3. 回答依赖了哪个知识库、附件、阅读选区、书籍或网页结果？
4. 回答是引用、引述或转述了具体证据，还是只是听起来权威？
5. 之前的轮次是被忽略、过度应用，还是与另一位学习者的上下文混淆了？
6. 模型是否说明了哪些内容未知、不确定或超出所选材料？

## 失败模式

| 失败模式 | 常见症状 | 可能原因 | 检查项 |
| --- | --- | --- | --- |
| 长程约束丢失 | 后续步骤忘记先前的定义、目标、记号、限制或更正 | 上下文裁剪、分支混淆、工具观察过多、约束重述不足 | 对比最终提示词的相关历史、会话分支和轮次元数据；在新轮次中重复缺失的约束，观察行为是否改变 |
| 检索漂移 | 回答切题但使用了无关来源，或回答了邻近问题 | 查询模糊、索引过期、来源混杂、top-k 过宽、缺少重排序或来源过滤 | 检查工具输入和检索到的分块 ID；每次只针对一个知识库或附件运行同一问题；重建或刷新过期索引 |
| 弱证据过度自信 | 确定性回答、评分、诊断或建议没有引用，或忽略矛盾 | 无检索结果、低置信度匹配、模型默认使用先验知识、缺少不确定性指令 | 检查检索是否返回空结果或低分结果；要求给出确切支撑段落；用仅依据证据的指令重试 |
| 反馈未基于材料 | 解释、测验答案或更正与上传的课程材料不一致 | 选错来源、书籍页面过期、引用定位符不匹配、来源冲突 | 对比引用的定位符、所选材料和当前来源版本；核实页码或章节锚点，以及来源是否已变更 |

## 检索失败模式

勾选最符合所观察行为的模式：

1. **未检索：** 工具可用但未被调用。
2. **范围错误：** 检索搜索了其他知识库、伙伴工作区、附件或用户上下文。
3. **来源过期：** 文档或索引在检索产物生成后发生变更。
4. **分块边界割裂：** 定义、表格、证明、代码块或图注被切成两半。
5. **近主题漂移：** 分块共享词汇但回答的是不同问题。
6. **关键词不匹配：** 来源使用的术语与学习者的问题不同。
7. **翻译不匹配：** 翻译后的查询与来源语言不对齐。
8. **分块重复：** 同一段落挤占了其他相关证据。
9. **top-k 过宽：** 弱匹配稀释了少量强匹配。
10. **缺少重排序：** 语义第一阶段候选在使用前未精炼。
11. **来源冲突：** 来源相互矛盾，模型静默选择其一。
12. **外部来源未核实：** 使用网页结果时未检查权威性、日期或佐证。
13. **引用不匹配：** 陈述与所引段落互不支撑。
14. **定位符不匹配：** 页码、章节、标题或锚点指向错误位置。
15. **结果为空或被过滤：** 访问、解析、MIME、语言或元数据过滤移除了所需分块。
16. **证据捏造：** 引文、数字、标题或引用不存在于任何返回来源中。

## 需收集的证据

提交 Issue 前，准备一份最小化且隐私安全的报告：

- DeepTutor 版本、操作系统、Python 和 Node 版本，以及安装方式。
- 使用的能力和模型，包括是否更改了推理强度或模型特定设置。
- 所选知识库、附件、阅读材料、书籍或伙伴工作区；除非可安全分享，否则不要上传私人文档。
- 相关用户请求和助手回答，已移除个人数据。
- 来自活动面板或 JSON 运行输出的工具名称、参数、结果摘要和引用 ID。
- 复现不匹配所需的检索片段或引用定位符。
- 重试、选择单一来源、重建索引或重述约束是否改变结果。
- 请求前后的服务器日志，已移除 API 密钥、令牌、本地路径、用户名和个人内容。

避免分享凭据、学生私人作业、个人标识符或机密文档。保留结构但经过虚构或缩短的来源摘录，通常足以复现检索问题。
